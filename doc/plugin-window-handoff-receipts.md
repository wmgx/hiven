# 普通工具独立窗口交接与旧稿保护

## 修复范围

复用独立工具窗口时，原实现只显示窗口、没有重接收材料，并立即关闭来源。现在普通 renderer 的交接带有原生请求编号、来源和接收窗口；只有新插件子树提交成功并得到匹配的 accepted 回执，来源才关闭。无新材料的普通窗口唤起仍保留原内容。QuickEditor 的归档和 owner 协议不变。

接收窗口已有稿件时使用现有 ConfirmDialog，默认继续编辑。因为部分工具尚未上报 dirty，任何既存 renderer 都保守确认，覆盖正文与参数修改。明确同意后保留旧实例、暂停其交付 owner，再建立新实例；拒绝、过期或载入失败丢弃新实例并恢复旧稿。接受后卸载旧实例。恢复时建立新 owner，旧回调不能复活。准备过程中会撤销旧异步交付，不承诺恢复正在运行的计算任务。

来源等待期间保持挂载并暂停编辑；取消或失败后恢复，现有反馈区说明未交接，可以重试。插件来源失效时立即请求原生取消。接收 ready 回调绑定具体实例，渲染错误同步阻断确认。回执传输不确定时保留接收侧两个实例并继续查询状态。

原生每个目标仅允许一个待处理请求，拒绝并发替换；请求 120 秒过期，UTF-8 上限为 10 MiB（包含序列化载荷），空文本有效，超限明确拒绝且不截断。只有来源可以取消，只有接收窗口可以确认；关闭或销毁窗口拒绝待处理请求。终态释放正文。等待确认时仅轮询小回执，不重复传输全文。

Diff 交接两侧完整文本、显示来源和用户选择的 Text/JSON 模式；快照不恢复原编辑 pane 的写穿绑定。未扩展任意插件权限或通用工作流。

## 验证

- 类型检查、架构边界、前端构建和原生 debug 构建通过。
- 原生模块测试覆盖大小、空文本、并发、取消、重试、旧回执、过期和窗口失效；JS 协调测试执行真实窗口宿主模块，确认 show 不能代替接收回执、失效来源不能开启交接，以及回执恢复。
- 既有无 payload 快捷窗口检查通过。
- 原生桌面使用隔离 profile 和合成文本，由 tauri-driver/WebKitWebDriver 读取界面、xdotool 操作真实鼠标键盘。最终构建通过已打包的 AppDir 运行；未发布安装包。
- Diff：首次移入核对双侧文本及 JSON 模式；编辑独立窗口旧稿、返回，再移入新双材料；默认取消后核对两边全文仍在；重试并明确替换，左右全文与 Text 模式正确，始终复用同一窗口。来源只在接受后回到 Launcher 根。
- 安全拒绝同窗交接后正文完整、复制可用；独立窗口的右侧全文显式复制并粘贴至外部 Mousepad，3036 字符完全一致。
- CSV 代表共享路径：既存窗口修改稿件、返回、新材料移入、取消保留两边、重试确认后接收新全文。
- 两次快速请求、取消后的晚回执以原生状态机和协调器验证；真实界面验证包含连续点击后不产生重复窗口。未通过真实 UI 注入原生通信断线或插件崩溃，不以逻辑测试替代这些场景的 UI 证明。

本轮未调用真实 AI API，未读取用户密钥或真实历史，也未改变历史记录设置。截图保存在隔离验收目录，独立复审未见视觉阻断。
