# CSV／JSON 转 Markdown 表格

复用 CSV Tools 的既有 `to-markdown` 路由、Markdown 输出选项、源／表／输出视图、全量处理、复制全文和原生另存为 `.md`。新增 JSON 搜索别名，不新增页面、导出系统或跨插件依赖。

## 数据规则

- CSV 按既有引号解析处理逗号、双引号和嵌入换行。标题行之后多出的字段补 `column_N` 列名，避免静默丢弃；补名避开已有标题。
- JSON 仅接受对象数组。单个对象、包含基本值、数组或 null 的行明确报错。列按各对象 `Object.keys` 的首次出现顺序排列（整数样式键沿用 JSON.parse／JavaScript 的对象键枚举顺序）。键名按原值保留，含空格及空字符串均不裁剪、不丢值。
- 缺失属性及 null 均为空单元格；字符串保留正文；数字、布尔值、嵌套对象和数组使用紧凑 JSON。只读取对象自身属性，`__proto__` 等属性缺失时不会误读继承值。
- 单元格按纯文本编码：`&`、尖括号及 Markdown 控制符转换为实体，竖线和反斜线不会改变表格列结构；源换行转为生成的 `<br>`。源内的 HTML／Markdown 不变为可执行 HTML 或格式指令。保留全部数据，不取表格预览替代完整结果。

输出视图给出规则说明。既有 1500 行预览上限不限制“复制完整结果”；大输入仍需完成既有全量处理，保存沿用原生受控另存（最多 10 MiB），取消／错误保持源和结果。用户明确选择的过滤／排序／投影照常作用于最终结果。

## 验证

- `node scripts/test-csv-markdown.mjs`：单元格编码、换行、HTML／实体／Markdown、竖线和反斜线。
- `node_modules/.bin/jiti scripts/test-csv-core.mts`：既有完整 CSV 回归及 JSON 精确键名／缺失属性／嵌套值、非法数组形状、CSV 引号换行、超过 1500 行的全文 Markdown、额外列与同步／异步结果一致。
- 原生搜索入口、输出预览、实际系统剪贴板和文件另存由集成验收统一执行。

Linux 原生验收：使用既有独立工具窗口，将含引号、嵌入换行、竖线、HTML 与反斜杠的 CSV，以及空键/空白键/缺失值/null/嵌套对象的 JSON 转换，完整复制并粘贴至外部编辑器，原始输入保留。另用 1605 行 CSV 验证超出预览范围的末行仍存在，外部编辑器全文一致。
