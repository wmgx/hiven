# Linux X11 显式窗口搜索与切换

## 产品范围

复用现有“窗口/window/切到”搜索与“切换窗口”入口。Linux 仅用户明确窗口意图时枚举，普通搜索、空搜索及应用启动不触发窗口抓取。没有新按钮、后台监测或系统权限。

仅支持确认的 X11 桌面，Wayland/XWayland 不冒充支持。只列当前桌面可见的普通外部窗口，排除 Hiven、自身系统窗口、最小化窗口及无法确认身份的窗口。不关闭、移动窗口或切换桌面。

## 身份、生命周期与隐私

结果使用短期 opaque token，标题只供当前内存搜索展示，不进入 usage、experience 或日志。Mac 原有窗口路径保留。Linux 不使用 Mac 的后台预热、标题记忆或 enrich 路径。

原生窗口实例和 Launcher 会话绑定列表请求，关闭/重开撤销旧列表；迟到列表不能复活旧会话。单份列表共用连接，被动接收销毁事件，不开后台轮询线程。选择时复核原 token、窗口、PID 与销毁状态，同名窗口不合并或猜选。

切换只使用正常 EWMH 激活请求，并确认实际 active window 与键盘焦点。过期、销毁、不可见或不受支持目标明确失败，不退回到按标题/应用猜测或注入输入。

## 验证记录

初始代码版本 `0ee89f1`，独审已收口。10 项窗口原生测试、18 项现有 paste/recovery 测试通过；TS 显式意图/零后台枚举/可见性/共享失败提示/旧会话行为通过，Switch Window 与 DesktopTarget 回归通过。typecheck、架构检查及最终前端构建通过。

旧 desktop-window-process-contract 的 getEmptyQueryTopApps 断言在未修改的 bc29b8f 基线同样失败，不在本批改动应用搜索。

初始正式包构建通过，但真实根查询无结果。串联真实 provider 与最终 rank 后确认：provider 已筛中两窗口，通用排序按完整带前缀 query 再次匹配使其被丢弃。末修 `bae34c0` 仅为 Linux 已按剩余标题筛中的当次候选增加临时 query alias，不改缓存/Mac/全局排序。新增真实 rank 回归覆盖两匹配、不匹配为零及查询变化不累积旧 alias，独审通过。

真实 UI 在 `bae34c0` 已显示两个合成窗口，但激活被拒。有限只读同实现 probe 证明候选身份、桌面与成员检查通过；该 Xfce 的 `_NET_ACTIVE_WINDOW` 为 WINDOW/32 两项且第二项为 0，原严格单值读取因尾随字节拒绝。仅该属性增加单值或恰一个零填充尾项的有界兼容，其他身份属性继续严格校验，焦点仍须精确目标与输入焦点后代两者确认。标准语义参考 [EWMH 3.8](https://specifications.freedesktop.org/wm/latest-single/)。

同轮发现瞬态窗口的固定按钮可持久保存无效 opaque key（不含标题），已在现收藏资格集合排除该类结果，鼠标与 Ctrl+P 共用守卫，普通工具与 Mac 不变。

末代码 `c2769ed` 的 active 兼容与瞬态收藏资格已独审通过；11 项窗口原生测试通过，末 typecheck、架构和前端构建通过。最终官方 AppImage 构建退出 0；首次轮询被工具取消后确认未完成，按同一官方流程恢复一次成功，没有变更权限或打包方式。真实 Linux Xfce/X11 正向：在末包 `c2769ed` 查询指定合成 Alpha 窗口，9.63 秒内选择；前台及键盘焦点实际到达 Alpha，另一 Beta 未被激活，Hiven 正常隐去。X11 候选固定入口已消失。负向仅关闭本轮合成 Beta 窗口，确认其消失后在候选出现 15 秒内选择旧项，显示窗口不可用；Hiven 保持前台，Alpha 及其他窗口未被误激活。该次未达到 30 秒列表 TTL，不能以过期拒绝替代销毁证据。协调者已亲看末候选、实际 Alpha 前台与 Beta 拒绝截图。

长路径窗口标题沿用现行尾部截断，公共前缀较长时可见名称辨识度仍有限；精确名称搜索已验证，不宣称该展示问题已解决。Wayland、最小化窗口及其他桌面不在支持范围，Mac/Windows 没有本轮真实桌面验收。
