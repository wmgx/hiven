# 内置插件 UI 盘点

## 判断原则

Launcher item 适合一次输入、一次变换、一次选择或直接打开目标。只有需要同时编辑多项内容、反复试调、持续预览，或需要在提交前完整审阅有副作用的操作时，才值得提供插件 UI。

新增 UI 直接复用现有 `ui.surfaces`、`PluginSurfaceProps` 和 surface shell；不新增通用表单协议，也不把所有插件强制成同一种交互。插件可以同时保留 item 快捷入口和 UI 工作区。

## 盘点结果

按用户反馈持续收敛：移除 Apple Passwords、Snippets；JS Filter/YAML 并入 JSON，行处理、命名转换和统计并入文本整理；已有 UI 的主要子功能提供 Launcher 直达入口。

## 本轮范围

本轮新增格式化、文本整理、日期时间工作台，完成文本对比入口与已有 UI 的子功能直达。沿用公共组件、现有转换逻辑和搜索管线，没有新增依赖或通用 UI 协议。飞书写操作和自定义命令输出页继续留待实际需求。

移除插件的源码备份位于本地 `temp/removed-builtin-plugins/`；用户配置未清除。当前内置清单为 18 个插件。

## 验收记录（2026-09-21）

- Web validation 使用桌面 bridge，验证了六个插件页面的 DOM、画面、主要交互和返回；验收期间无新增控制台错误。
- JSON 表达式显式执行、结果转输入/压缩；计算器 `0.1 + 0.2 = 0.3` 与历史；随机范围/数量/颜色；CSV 输入/表格/去重/筛选/输出；正则定位/错误/Unicode 零宽匹配；大爆炸全选/反选/清除均已验证。
- 构建、架构、diff 检查及相关逻辑回归通过；六个插件实际释放目录与源码逐文件一致。没有执行真实上屏粘贴、外部打开或用户数据删除。
- 全量 TypeScript 检查仍有原有 21 个诊断，无新增；全局 i18n 检查仍被 `ObservationSettings.tsx` 的既有内联语言分支阻塞。本轮六个插件的文案 key 均有中英文对应。
- 原生窗口在 macOS 上的逐帧位置变化未做实机截图验证，沿用已通过的窗口几何回归检查。
