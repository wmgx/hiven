# 工具完整文本结果的原生另存

## 目标与边界

CSV 的完整结果原先使用浏览器 Blob URL 下载，没有原生写入回执；超过 1 MiB 的结果也无法通过带回搜索后的材料另存解决。本批将原下载按钮替换为“另存完整结果”，复用宿主已有文本导出的原生对话框、一次票据和原子写入内核。

公共能力仅接受文本快照、建议文件名和取消信号，不接受或返回目标路径。保存位置由用户在原生对话框选择。Surface 文本上限为 10 MiB UTF-8；根材料另存仍为 1 MiB。未新增插件私有存储权限、任意文件读写入口或后台保存。

只有 native 确认落盘才报告成功。取消保留结果并允许重试；输入/参数或 owner 变化撤销尚未提交的保存。提交被 native 接受后，写入结果仍按事实返回，旧页面不向新页面发送成功提示。浏览器或 relay 不具备此原生能力时明确报告不可用。

## 验证

候选代码 `1c58224`，CSV 插件 `1.9.7`，内置索引 `113`。

- 原生文本导出 16 项测试及 bridge 私有命令排除测试通过；覆盖 root/surface 限额隔离、所有者撤销、窗口 token、票据消费、TTL 与原子写入边界。
- 157 个 CSV 生产组件场景通过；保存专项覆盖空结果、字节上限、取消/错误、双触发、参数变化、普通重渲染和晚回执。
- surface saveText 专项及根材料另存、退出 dirty、PNG 导出相关回归通过；类型检查、架构检查、内置释放 12 项/200 源文件一致性、差异检查及前端构建通过。
- 既有 CsvSurface lint 基线保持 42 errors/7 warnings，各 rule 数量未变；未宣称全仓 lint 通过。csv-core 以 Node 24 strip-types 与本地扩展名解析器执行原测试通过，未安装缺失的 tsx。
- 冻结后独立复跑 surface 保存、CSV 157 场景及根材料导出通过；最终差异检查通过。官方 Tauri debug AppImage 构建退出码为 0。

### Linux X11 真实 UI（2026-10-10）

同一候选 `1c58224`，隔离合成 QA 进程 20235，父 shell 20234 保留退出码记录。正常文件入口导入 8105 行、1423176 字节 CSV；完整处理后为 8105×3，界面明确显示预览最多 1500 行、另存 10 MiB 和带回 1 MiB 的边界。

- 原下载槽的“另存完整结果”打开原生保存框。填写新的 QA 文件名后取消，实际检查该文件不存在；原结果和保存入口仍可用，没有假成功提示。
- 同一结果再次点击另存，用户路径仅在原生对话框选择。保存后按钮恢复可用，结果保持，未见错误。
- 新文件实际为 **1852726 字节**，超过 1 MiB；独立 JSON 解析得到 **8105 个对象**，每项 id/label/payload 与原 CSV 独立解析的全部行逐值相等，头尾 id 为 1/8105，中文与逗号、长正文均保留。
- 独立设计审查看实际截图，原动作位置、保存中/取消返回和稳定结果页未出现新增布局阻断。

证据边界：保存前后两次观察之间没有捕获短暂成功 toast，不能写成成功提示已截图验收。完整落盘由新文件实际内容证实。未为抓 toast 再次写文件；未操作真实用户数据、CtrlV、付费 API 或系统设置。独立工具窗口生命周期由逻辑/native 测试覆盖，本轮真实对话框在 Launcher 内 CSV；macOS/Windows 未实测。
