A · 系统设置

更疏、控件更大、工作面浮起明显、圆角更圆。像 macOS 偏好设置：好认、好点，略占空间。
  • 行高 ~52 / 插件 ~58
  • 图标盒、分组标题更醒目
  • 阴影与卡片感最强

B · 效率工具

更紧、几乎无浮起、列表像 IDE 设置。扫得快、装得多，但容易再次觉得「扁」。
  • 行高 ~40 / 插件 ~44
  • 无卡片阴影，分割线为主
  • 插件次行优先路径元数据

C · 中间档（先前推荐）

系统感外壳（侧栏抬起工作面）+ 效率密度列表。立体靠层级，不靠厚拟物。
  • 行高 ~46 / 插件 ~50
  • 轻阴影 + 发丝边
  • 插件次行是描述，不堆路径

切换 A/B/C 与「设置 / 插件」对比。选定后告诉我字母，再落详细规格与实现。
