# 显式设置字段搜索与定位

## 用户路径

在全局搜索输入 `设置 图片` 或 `settings image`，可用字段以字段名称和插件、分组归属出现在原结果列表。选择结果后打开原插件设置页，滚动到字段并将焦点交给可用控件；返回沿原设置导航恢复搜索。没有新增设置页面或分类框架。

字段检索只在明确的 `设置` / `settings` 前缀及非空关键词下启用。普通查询、空查询和原插件设置入口保持原行为。搜索只读取静态 schema 的安全标签、描述和稳定标识，不索引字段值、默认值、选项内容、密钥或用户记录，也不执行动态 schema 回调或解析自定义设置组件。

## 边界

不可用或无法可靠静态判断的声明不生成字段候选；执行时再次复核插件与权限。现有设置入口仍保留。字段定位按 section id 与 field key，不根据用户内容构造选择器。禁用、复合或没有合适控件的字段只定位分组，不触发按钮、切换或授权。

定位完成或用户开始交互后停止自动滚动；换目标、关闭和生命周期变化清理旧请求。仅聚焦后返回不应写入设置；列表文本字段保持未修改时不提交的行为。

## 验证

真实 registry、ranker 与桥接测试覆盖中英文显式查询、普通搜索不变、静态安全读取、来源及权限变化。导航的 10 项生产回调测试覆盖延迟 DOM、取消定位、控件不执行、未修改列表不写入，以及晚到排名后的查询与选中恢复。独立审查通过；全仓类型、架构检查及前端构建通过。

首个官方包 `56414a6` 在 Linux X11 隔离 QA 中实际验证了两条路径：`settings images` 唯一命中中文“记录图片”，Enter 打开原页并滚动聚焦已有开关；`settings max total cache size` 定位到长设置页底部数值输入。未点击开关或修改数值；Esc 一次返回原查询、原所选字段和搜索焦点，并可继续键入。协调者和独立设计实际查看了定位与返回证据。

精确中文前缀因输入工具返回文本偏移错误而未完成真实键入，确认查询仍为空，没有将其归为产品查询失败；中英文前缀与匹配语义由真实排名模块验证。界面实际使用中文标签。搜索初始为 660×560，设置页 744×584；返回后紧凑尺寸异步恢复，不声称首瞬间尺寸已完成还原。
