# Cron 搜索即时答案

时间助手复用原搜索即时答案，支持直接输入五字段表达式或 `cron ` 前缀。`*/5 * * * *` 显示「每5分钟」和严格晚于查询时刻的下次完整日期、时间、UTC 偏移及系统 IANA 时区。回车时以原结果的时区重新计算严格晚于执行时刻的下次时间，刷新失败不复制旧值。复制解释；不保存配置、不创建任务、不调用网络。

支持分钟、小时、日期、月份、星期，数字列表、升序范围、正整数步长，以及英文月份／星期名。星期 0 和 7 均为星期日。不支持秒／年份字段、Quartz 的 `? L W #`、`@daily` 等宏、随机散列或附加命令。无效表达式返回明确错误，不猜测方言。

按 Vixie Cron 的字段首字符规则：日期和星期都不以 `*` 开头时按 OR 匹配；任一以 `*` 开头时按 AND 匹配，并在结果中明确说明。`*/1` 仍带星号标记，不能当作限制字段而吞掉星期约束；`*/2` 与 MON 同时出现时，只匹配奇数日中的星期一。依据 [entry.c 的星号标记](https://github.com/vixie/cron/blob/master/entry.c#L210-L245) 和 [cron.c 的匹配条件](https://github.com/vixie/cron/blob/master/cron.c#L281-L301)。`*/7` 分钟不会被错误解释为连续每七分钟，因为跨小时时间距可能不足七分钟。

默认时区来自本机 `Intl`。按本地日历有界搜索八年；不存在的日期不滚动到下月。夏令时跳过的本地时间不匹配，回拨重复时间的两个真实时刻分别匹配。UTC 偏移用于区别两个同名本地时间。仅预览下次匹配，不承诺其它 Cron 实现的任务补跑／重复抑制策略。

`scripts/test-cron-answer.mjs` 覆盖严格晚于当前时刻、分钟步长／范围／列表、DOM/DOW OR、英文名、世纪闰年、二月三十日、New York 跳时和重复时刻、Lord Howe 半小时回拨、Apia 跳过日期、Kathmandu 偏移及错误方言。`TZ=Asia/Shanghai node scripts/test-date-time-assistant.mjs` 保持此前时间戳和时区即时答案回归。真实 UI 主例及错误流程由集成者验证。

Linux 原生验收：五字段主例展示下次完整日期时间、系统时区和规则，Enter 完整复制；六字段 Quartz 式输入明确拒绝且剪贴板不变。复制时刻刷新与 DOM/DOW 星号规则修正使用动态入口逻辑测试验证；DST 边界为算法验证，不创建真实任务。
