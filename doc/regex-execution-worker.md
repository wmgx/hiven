# 手工正则的可终止执行

正则测试器的独立页面和编辑器内面板都在本地独立 Worker 中编译并执行表达式。实际已有操作是匹配与提取；没有替换、replacement 或 split 输入，本批不新增这些操作。

每次请求创建独立 Worker，最多一秒（含启动、编译和匹配）后真正 terminate。修改 pattern、flags、样本文本或离开页面会立即取消；卸载和宿主 owner 失效同样终止。控制器请求身份与 UI 输入/owner 身份共同防止晚回覆盖新结果。主线程不再执行用户提供的正则。

保留原匹配算法：global/non-global、捕获组、位置、Unicode 零宽推进以及最多 1000 个匹配。合法无匹配、仅空匹配、编译错误、执行超时和 Worker 加载失败分别表达；不将超时伪装成零匹配。原条件和文本保留，修改后自动重试。反馈复用原结果区域，无新增面板、按钮或权限。

提取仍使用当前完整匹配集合，沿现有返回搜索与复制路径交付；等待宿主回执，拒绝时可重试，编辑/退出会撤销交接，旧定位回调不会选中新文本的旧位置。

## 打包与边界

Worker 位于插件内部，通过 Vite `?worker&inline` 编入插件资源，不依赖开发服务器或运行时源码相对 URL。不改 framework、不增加任意插件权限。第一方插件正式入口仍走原 bundled loader；外部目录插件如重新分发该源码，须先按原目录插件要求编译为可加载 JavaScript，不能直接把 TS/Vite 查询导入当作原生 asset 模块。

## 验证

重要逻辑测试使用实际 Worker 运行原算法：病理回溯被 terminate、父线程心跳存活、随后恢复、取消/晚回隔离、无匹配/非法输入、Unicode 与原匹配上限。原提取语义测试、类型检查、架构检查及生产前端构建通过。没有增加 CI 触发或样式单测。

真实 Linux 原生验收使用官方 AppImage 与隔离 profile，页面为 `tauri://localhost` 内嵌生产资源，Tauri IPC 存在、浏览器桥接未启用，不依赖 Vite。完成：正常表达式正确 → `^(a+)+$` 对 40 个 a 加叹号触发超时，主页面心跳持续且文本保留 → 修改为 `a+` 恢复 → 用合成多行文本匹配 150 条（只预览 100 条）→ 提取回搜索 → 现有复制动作。系统剪贴板与全部 150 行、2739 字符逐字相等，复制前置入哨兵文本以排除旧剪贴板误判。

WebKit WebDriver 的逐键文本输入会丢换行，因此多行样本改用真实系统剪贴板显式粘贴；这不是产品截断。未读取真实历史或用户数据，未调用模型/API。其他平台未做原生 UI 验收；本批不发布应用或部署。
