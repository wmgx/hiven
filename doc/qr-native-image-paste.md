# 二维码显式图片粘贴

## 目标与界限

识别页的用户粘贴动作可在原生桌面读取一次剪贴板图片，避免依赖 WebKit 是否提供 DOM 图片 MIME。仅显式操作读取，不轮询、不启动历史采集、不写插件图片库存。文件选择与浏览器 DOM 图片/Data URL 路径保留。

## 公共能力

活动插件 surface 可获得可选 `clipboard.readImage`，返回内存 PNG 字节、类型及尺寸。实际原生桌面与有效 owner 才提供；浏览器桥接不冒充原生能力。要求现有 `clipboard.read` 和 `clipboard.image`，读取各异步阶段复核权限与不可复活的原 owner 生命周期。

先读取尺寸再复制 RGBA：单边最多 8192、最多 16 Mi 像素/64 MiB RGBA、PNG 最多 10 MiB。此限制避免继续把超限图像复制到 JS，不承诺操作系统读取剪贴板本身零分配。原生 Image handle 无论成功失败均释放；PNG 编码后的 canvas 清空。

原生错误无法可靠细分“无图片”与读取失败，统一给出可恢复的读取错误，不猜测剪贴板内容或权限状态。原生图像读取失败后，只有 `NotReadableError` 可沿同一显式请求检查图片 Data URL 文本；权限拒绝、取消及超限不触发该回退。回退固定原 clipboard 对象并传递同一 AbortSignal，防止新 owner 或换图后的旧请求继续读取。

## 页面交互

Ctrl/Command+V 仅在识别页、非文字编辑目标且不处于输入法组合时触发原生路径。浏览器 DOM 路径保留，原生手势不会同时重复解码 DOM 事件。文件、Data URL、原生图片与初始图片共享请求代际，换图、切换模式及卸载作废旧结果。预览 object URL 在替换/退出时撤销。

没有新增按钮或面板；错误和识别结果使用现有输出区域。

## 验证

代码版本 `7a3ad45`。typecheck、架构检查、最终前端构建、新 SDK 测试入口、QR 真实解码/会话逻辑及插件源码释放检查已通过。独审使用实际 Renderer factory 验证关闭、重开、换目标与权限撤销，确认 Data URL 回退固定原 host、与图像读取共用取消信号。

原生图片读取既有合约和资源释放回归通过；未运行全算法矩阵。官方 Tauri Linux AppImage 构建 exit 0。新 QA PID13461 使用代码 `7a3ad45`，原 profile 的历史及图片记录开关原本已开启，本轮未更改采集设置。

真实路径：新生成公开合成文本 `Hiven image QA 7a3` 的二维码并复制图片，History 出现对应 256×256 PNG；在真正前台合成编辑器复制普通文本替换剪贴板，History 中也可见该文本，再取回原图。识别页非编辑区域明确 Ctrl+V 后，图片预览与原文完整显示，复制文本动作可用。

随后在真正前台合成编辑器复制普通文本，识别页 Ctrl+V 显示“无法读取剪贴板图片，请重新复制图片或选择文件。”，旧结果清空且复制动作禁用。正常选择此前已保存的合成 PNG 后恢复准确 `Hiven QA123`。成功、错误和文件恢复三态截图均实际复核。

本批真实验收为 Linux X11 中文界面、原生一条 History 图像闭环；浏览器 DOM/Data URL、输入焦点、IME、权限撤销与迟到资源释放由逻辑覆盖，未把它们列为真实跨平台验收。未测试所有图片格式、巨图或其他平台系统剪贴板。
