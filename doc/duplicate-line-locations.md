# 查重复行

line-tools 3.3.0 复用文本工作台输入、结果区和完整复制。搜索“查重复行”/“find duplicate lines”直接选中操作；原“去重”操作不变。

`A\nB\nA\nA` 显示 `"A"`、3 次、原始行号 1、3、4。点击行号或 Tab 到按钮后按 Enter，聚焦原输入并用真实 selectionRange 选中该行。行号按 CRLF、LF、CR 分隔的原始行计数，与视觉换行无关；该操作输入框暂不软换行。定位时按 textarea 实际归一化后的值计算 UTF-16 范围，支持非 BMP 字符。

默认精确匹配，独立的“忽略大小写”和“忽略首尾空白”开关默认关闭，不继承排序/去重/清理的选项。匹配规则改变不修改原文；合并显示时使用该组第一次出现的原始文本，保留所有原始行号。空白行和末尾空行计入，空输入保持空态。JSON 风格引号表示原文，令空行、Tab 和边缘空白可辨识。

完整复制清单格式为 `"A" ×3 [1, 3, 4]`，一组一行。全文计算，不自动去重、不覆盖输入。无重复时显示原文不变提示，复制不可用。每页最多 20 组、每组每页最多 40 个行号按钮，明确显示总数与页码范围；翻页不改变完整复制结果，避免大输入产生无限 DOM。

逻辑验证：`node scripts/test-duplicate-line-locations.mts` 与 `node scripts/test-text-workbench-model.mjs`，覆盖精确及显式规范化、空白/尾行、混合换行、Unicode UTF-16 位置和十万次重复全文清单。原生 UI 定位、键盘与系统剪贴板由集成者验收。

2026-10-11 Linux原生验收：`A\nB\nA\nA` 点击第3行选中真实输入范围4–5，Tab+Enter第4行选中6–7；返回时取消丢弃后原文保持，复制清单 `"A" ×3 [1, 3, 4]` 到外部Mousepad后全文一致。分页规模与混合换行由逻辑验证覆盖。
