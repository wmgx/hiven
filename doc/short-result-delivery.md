# 短结果的参数归属与复制

随机工具保留上一成功生成批次，并在原计数位置提示当前参数已变化、尚未重新生成。比较使用与实际生成共用的有效参数（截断、默认值、范围规范化等），等价编辑和当前模式无关字段不误报。点击生成成功后才替换快照；失败显示错误并保留旧批次，标题与色块仍属于旧批次。切换模式沿原合同生成，不引入后台生成或新结果历史。

计算器在原快捷键提示行提供可点击和可聚焦的「复制结果」，与原快捷键使用同一完整结果和处理函数。无结果或无效表达式时按钮禁用；现有键盘、输入法和选择保护不改。

## 验证范围

实际参数模块测试、基线生成语义对照与独立审查通过；最终 npm 测试入口和插件源码释放检查通过。旧 random-and-variable-case 聚合脚本因既有 line-tools extractTextList 加载缺口失败，未扩大修复它。

本批没有宣称随机结果的密码安全性、概率分布或所有算法正确性，也没有改动既有异步复制完成后的生命周期边界。末版 `4e68324` 类型检查、Vite 构建及官方 AppImage 打包均 exit 0。新 Linux X11 QA 实际确认：修改随机范围/数量后保留五条旧结果并标尚未重新生成；点击生成后显示符合范围的三条并撤下旧批次提示；非法最小值大于最大值时显示错误并保留三条旧结果。计算器新按钮可 Tab 聚焦并显示焦点环，Enter 激活后复制到新 Mousepad 得到精确 `12`；无效算式时按钮 disabled。本轮验证了键盘激活，没有另做鼠标点击或重复算法/概率测试。
