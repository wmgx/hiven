# CSV 完整结果带回搜索

## 起因和边界

2026-10-10 的 Linux X11 实测中，固定合成 CSV 的 8100 行经完整处理得到 8100×2、约448.7KB JSON。既有下载仍使用 Blob URL 与 anchor.click；一次正常前台鼠标对照没有保存框或结果反馈，在已知 Home/Downloads 的唯一合成基名检查中也未确认产物。因此只记录下载落盘未确认，不推断所有平台或全部目录均失败。

本批复用已有用户可见的材料交接与当前文本另存，不新增原生写入接口、SDK 或权限。CSV 现有动作栏只增加“带回搜索”，原复制及下载保留。带回后由用户显式选择已有“另存当前文本”，默认文件名仍为该功能的 result.txt，用户可修改。

## 内容与生命周期

代码版本 `04d3176`，CSV 版本 `1.9.5`。小表序列化全部当前数据，不使用选区或最多1500行的预览。解析触及上限时，必须有属于当前完整源文本和参数的已完成全量结果；额外精确快照避免旧长度与首尾字符指纹遗漏中段编辑。只按字符长度较大但实际解析完整的少行文本无需额外全量处理。

点击时取得完整输出快照，并按 UTF-8 字节限制在1MiB内；合法空结果不会因字符串假值被拒绝。超限保留输出并明确报错，不截断。编辑、读取新文件、换宿主或退出会撤销待交接；重复点击不发起第二次请求。仅确认接收后沿原宿主语义离开，拒绝或失败保留当前结果，不让迟到回执清除新会话。

既有材料交接含 pending localStorage 备份/跨窗请求。本批不新增正文库存，也不声明零落盘、无限大小或修复原大文件下载。

typecheck、architecture、内置释放12项行为检查及197份源码校验、Vite构建均通过。官方 Tauri debug AppImage 构建 exit 0。
