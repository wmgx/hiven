# cURL 本地解析

`curl-inspector` 是独立内置插件，由现有目录 glob 发现。启动器只搜索工具名称；命令在工具内部输入，忽略 initialText，不捕获剪贴板，不注册参数/即时答案。启动器现有查询遥测不适合粘贴凭证，因此 UI 明确提示不要把原始 curl 放进搜索框。插件没有存储、遥测、日志、网络、命令执行或文件读取调用。

## 支持范围

只解析 POSIX 引号、转义与反斜杠续行。要求单个 HTTP(S) URL，支持 `-X/--request`、`-H/--header`、`-d/--data`、`--data-raw`、`--url`、`-I/--head`，长选项等号形式及 X/H/d 的紧接值形式。多个 data 用 `&` 连接，默认 POST，显示 data 的默认 Content-Type；显式方法大小写原样保留。显式请求头按原顺序保留重复项。

不模拟实际传输自动生成的请求头、环境或 curl 配置。未知参数不忽略，返回具体类别的说明且不展示部分请求。拒绝文件输入、配置、form、data-binary、json、跟随重定向等未支持选项。拒绝未引用的 Shell 特殊符号/通配符、变量/命令展开、管道/重定向/多条命令；单引号中的相关内容仅视为字面字符串。引号未闭合、URL 展开、多 URL、请求头删除/空值简写、HEAD 与 body/显式方法组合均拒绝。

输入总上限 100,000 UTF-16 单元，超限保留原文不截断。工具是解释给定命令的有限语法，不声称复现用户机器的完整 curl 执行环境。

## 凭证与复制

URL、全部请求头值、body 与原文默认遮挡。原文使用原生 WebKit 支持的 textarea 文本遮罩，仍保留内部编辑值；遮挡防止视觉泄露，不是对 DOM、开发工具或具有系统权限的观察者加密。各部分通过明确「查看」或「复制完整值」按钮访问，键盘可操作；复制不会自动粘贴。显示过的解析字段在编辑原文后重新遮挡，原文显式查看状态保留以便编辑。

复制使用已有 `host.clipboard.writeText(text, { recordInHistory: false })`，由集成者添加 pluginId 的受限白名单；若宿主/浏览器不支持，不回退普通复制。错误只展示固定本地化分类，不回显输入/系统错误。标准 Ctrl/Cmd+C 也拦截到相同的 history-free 写入，剪切禁用并提示使用复制。复制可被外部系统剪贴板管理器观察，插件只承诺自己的复制不录入 Hiven 历史，不保证用户进入工具前复制原文未被既有历史记录。

既有 Observation 的截图与键盘采集共用固定 hiven/com.hiven.app 排除规则；插件没有全局 textarea 输入遥测注册。浏览器 validation 不是 Hiven 原生进程，不能据此承诺浏览器画面被 Observation 排除。

## 验证

`node scripts/test-curl-inspector.mjs` 使用合成 URL、凭证和数据，覆盖完整字段、多个 data/重复 header、引号与续行、空 body、显式方法、IPv6、文件/配置/执行拒绝、未知参数、超长输入等。测试不执行 Shell 输入、不读取引用文件、不访问网络。原生真实 UI、遮挡画面、键盘复制与宿主历史排除由集成验收完成。

## 本轮原生验收

2026-10-11，Linux 隔离 profile、合成 URL 与 Authorization：真实输入后默认原文及字段遮挡；显式展开 header，复制 URL/header/body 均逐字完整；@file 被拒绝且源文保留。临时启用仅含合成数据的 Hiven 历史，复制 header 前后 history/index 完全一致，随后恢复历史关闭。没有发送请求或读取引用文件。键盘复制的事件拦截有逻辑检查，本轮原生主要验收按钮复制。
