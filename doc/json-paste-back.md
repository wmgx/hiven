# JSON / YAML 工作台：结果回送原应用

## 本批范围

JSON / YAML 工作台此前已有替换输入、带回搜索、复制，但缺少其他文本工具已有的直接回送出口。现在结果栏增加“粘贴回原应用”，复用宿主 `paste.pasteText` 和已有 `accessibility.paste` 权限。插件版本为 2.5.11。

不增加宿主协议、工作流、选区捕获或自动读取剪贴板。格式化、YAML 转换、表达式等共用当前结果交付；合法的空串、0、false 不按文本真值过滤。

## 生命周期与反馈

- 复制和粘贴共用交付锁，等待结束前不发出第二次交付或返回搜索。
- 输入、操作、参数、表达式运行、返回和关闭同步作废旧回执；已发出的剪贴板/粘贴 I/O 无法取消，但旧回执不能关闭新草稿。
- 反馈绑定当前结果与宿主 owner。成功且仍属于当前结果时才完成；失败保留输入、结果和重试入口。
- `fallback: copied` 在原状态区持续提示已复制但未自动粘贴，不能当作成功关闭。再次编辑会清理过期反馈。
- 结果栏允许换行，适配新增按钮；中英文文案均使用 locale。

## 验证记录

在隔离 AppImage profile、Xvfb + xfwm4 的实际 Linux X11 会话中，通过官方 tauri-driver / WebKitWebDriver 操作原生 Wry 页面，确认 Tauri IPC 存在、浏览器桥接未启用。X11 会话显式设置 `XDG_SESSION_TYPE=x11`，没有放宽产品的平台判断。

主链：Mousepad 为原应用 → 合成 JSON 写入系统剪贴板 → Launcher 显式粘贴并选择“Use as content” → 打开 JSON / YAML 工作台 → 清空后输入带中文、多行字符串、数组和布尔值的新 JSON → 检查左右完整 Monaco 文本 → 点击 Paste back → 自动恢复 Mousepad → 只执行保存，文件与格式化结果全文相等（116 字符）。未用手动粘贴代替自动回送。

同链失败验证：处理过程中关闭原 Mousepad 窗口，再交付，原状态区持续显示 copied fallback；左右全文、草稿和可重试按钮均保留，再试仍不会假成功关闭。未启用历史记录、读取真实历史或调用真实 API。

支持检查：类型检查、架构检查、生产构建、交付反馈生命周期测试、JSON 结果交付逻辑测试通过。同步修复旧宿主测试夹具遗漏的 History 引用，不改其产品实现。实际 UI 验收与逻辑测试分别记录，不相互替代。

本次未重新测试其他平台；其回送能力继续由已有宿主判断。未发布应用或部署。
