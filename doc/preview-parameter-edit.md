# 在预览中修改单个参数

Global Launcher 的纯文本明确预览会显示可编辑的完整参数摘要。点击某一项，修改并确认后直接更新当前预览，其余参数无需再次填写。此入口只用于受支持的纯文本工具，不自动重跑 AI、网络请求或有外部副作用的动作。

取消或 Escape 返回原预览和原参数，不重新计算；命令标签的 × 保持退出整条命令的行为。编辑期间旧结果不能交付。材料、会话或插件契约失效时，保留原文回到输入页并提示，不恢复陈旧输出。

预览、编辑和取消不保存设置。只有成功复制或带回后，现有“保存操作”入口才可保存本次实际使用的参数和输出目标。从已保存动作进入后修改参数，也只影响本次运行；原保存项不被自动改写。成功交付后可另存本次设置。传统选区/全文绑定的旧保存项不提供这个编辑入口，以免重读隐藏编辑器内容。

按 Tab 可访问每项参数按钮，Enter 或空格激活对应按钮；其键盘事件不会误触复制或带回。

关键回归：`npm run test:launcher-preview-parameter-edit`。覆盖单项重算、取消恢复、旧回调隔离、材料/插件失效，以及修改保存项后交付、另存和新输入回放的一致性。

## 桌面验收

官方 AppImage 在隔离 Linux Xfce 配置中完成 JSON 与清理名单的真实操作：所有参数可见，单项修改直接返回新预览；Tab/Enter进入编辑不会误交付；Escape和取消恢复原预览；×退出命令。已保存Return操作改参后另存，新项保留本次参数与Return目标，原保存项不变。

长JSON预览可独立滚动到底，参数、Copy/Return和底部提示保持完整可见；名单三个参数亦未被折叠或裁切。忙态因合成小输入处理过快未在GUI中观察，相关互斥由controller行为回归覆盖。此桌面验证不代表其他平台或全部窗口模式已验收。
