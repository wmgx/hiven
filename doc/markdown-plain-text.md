# Markdown 转纯文本

`line-tools` 3.6.0 在现有文本工作台增加单个操作和中英文搜索入口。沿用输入／结果、复制、回填和返回保护，不新增参数、权限、转换框架或工作流。

## 固定规则

使用已锁定的 marked 14.0.0，独立实例按 GFM 解析，仅输出文字。标题、粗体和斜体去掉展示标记；保留列表层级和序号、引用前缀、任务勾选及删除线标记，避免改变语义。

链接输出文字、地址和可选 title；自动链接避免重复地址。图片保留 alt、地址和 title，不读取图片。所有引用定义（包括已用、未用、重复）在原位置保留；正文引用使用首个有效定义。定义不能打断普通段落，代码块内的定义样式文本不参与引用解析。脚注等未支持语法保留字面形式。

表格输出表头和全部行，以 Tab 分列，保留空单元格；单元格内部的反斜杠、Tab 和换行做可辨识转义。源数据列多于表头时保留整个表格的文字形式，避免 marked 默认截掉多余列。

代码块保留正文、内部缩进和语言标记；行内代码从原始 token 去掉成对反引号，不使用 marked 已转义／归一化后的 text，不做实体解码。普通文本实体也保持字面形式。HTML 标签、属性和内容作为文字保留，不生成 DOM、不执行脚本、不加载资源。段落分隔采用空行；解析器归一化换行，不能把输出当成字节级 Markdown 备份。

## 有界执行与交付

输入最多 128 KiB、完整输出最多 512 KiB（UTF-8）；转换遍历最多 20,000 节点、64 层。解析和转换在可终止的独立 worker 执行，1 秒截止后终止。marked 内部仍有递归，线程隔离与终止负责阻止它卡住界面。超过任何边界均失败，不输出截断内容，源输入保留可纠正。

结果绑定输入、修订号和图片标签语言。编辑／返回撤销旧结果、终止旧 worker，旧回执不能启用复制。复制沿用已有交付门禁并透传取消信号；不承诺撤回已经发生的原生写入。

## 验收（Linux，2026-10-14）

隔离 profile、实际 Tauri/WebKit 桌面、合成文本、独立 GTK 文本接收器。未调用真实 API、读取用户数据或改变历史记录设置。实际释放插件版本 3.6.0。

真实流程通过：搜索入口 → 粘贴 `scripts/fixtures/markdown-plain-text.json` README → 核对结果全文 → 返回确认并取消 → 显式复制 → 在外部程序粘贴，全文与期望一致，包含 Tab 空列、代码实体、所有定义及结束标记。英文界面图片前缀为 Image。

输入超限时源文保留、复制禁用，纠正后可复制完整新结果。复杂输入实际显示 Converting 时立即修改，等待原任务期限过去后仍只有最新结果，外部粘贴全文一致。

合成 HTML 包含 img、script、iframe 和 stylesheet URL。真实界面结果及外部粘贴保持字面 HTML；无注入元素、脚本探针变化或对应 resource timing；本地 HTTP 探针没有收到请求。

必要逻辑验证分别覆盖实体／引用／表格／规模边界和受控 worker 的迟到回执、终止、超时及纠正。受控测试不冒充真实 UI。独立语义与交互审查通过，架构检查、前端构建和 Linux 原生 debug 构建通过。
