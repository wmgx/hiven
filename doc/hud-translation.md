# HUD 单次翻译

本功能以用户已经明确复制的公开文本为输入，通过翻译 Surface 已绑定的快捷动作启动单次会话；不打开 Launcher 或翻译页面。首期只允许 readiness 已确认且支持真实 AbortSignal 的 AI profile。传统网络翻译尚无底层取消协议，不进入该入口。

产品边界：

- 读取前先确认 profile、provider、model 与权限可执行；未准备好时不读剪贴板。
- readiness 未通过时显示 15 秒不可聚焦的通用不可用提示，不读取剪贴板或暴露 provider 原错；后续显式快捷键会强制刷新元数据并重试。
- 读取一次公开文本后复用现有 secret / secret-like 分类，敏感、空、含 NUL 或超限输入不发送且不进入 HUD。
- 源文、完整译文与 provider 错误只存在单会话内存，不进入 toast、telemetry、历史或磁盘；被动 HUD 只接收限长预览，显式激活后完整译文才会定向进入该 HUD，复制使用未截断的完成结果。
- 一次只有一个会话。运行中或结果态再次触发都会进入 active，不取消翻译。新会话、取消、过期和关闭均使旧 delta、完成与错误失效。
- 普通 `toast-hud` 保持原固定回执、不可聚焦和鼠标穿透协议。翻译使用共享的短期文本结果 HUD 安全部件与独立产品会话；不会与二维码会话同时占用窗口。
- active 在当前显示器工作区内扩展为有界阅读窗，正文可用键盘滚动且长无分隔文本不会横向溢出；Tab 顺序为正文、复制、关闭，Esc 关闭。
- 被动会话最多保留 15 秒；显式激活后由原生层一次性改为最多 2 分钟，不因内容更新或重复触发续期。
- active 只提供复制全文与关闭/取消，不自动粘贴、替换原文、保存历史或创建 workflow。用户主动切走后，本会话不再恢复旧焦点。

Linux X11 已通过 AppImage 原生链验收：外部编辑器中的真实全局快捷键可进入被动/active 两阶段，正文可滚动到底，完整复制逐字一致，Esc 可退出并恢复原目标。active HUD 仅在确认实际获得焦点后监听失焦；用户 Alt-Tab 或点击其他应用时会取消会话并立即隐藏，不恢复旧目标焦点，同会话迟到更新不能重开窗口，下一次显式快捷键会创建新会话。验收使用隔离配置、合成剪贴板文本与受控本地 provider，不读取真实用户数据。macOS 与 Windows 尚未实机验证。
