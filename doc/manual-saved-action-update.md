# 手动保存工具更新与旧自学习撤除

## 显式更新

已保存的纯文本、纯函数、每次输入（prompt）工具，在现有预览编辑参数并成功交付后，可从原“保存上次运行”入口选择更新原工具。确认页显示前后参数与输出目的地；输入新名称仍可另存。预览、复制与取消本身不修改原配置。

运行携带实际来源 ID 与执行时配置快照，不从最近记录猜测。更新保留 ID、名称、别名、创建时间，写入参数、输出目的地和更新时间，不保存输入正文。当前契约、权限、来源删除或快照变化均在确认时复核；失效时拒绝覆盖，可返回命名页另存。最终检查和写入在同一同步调用内完成，沿用现有单 Launcher 存储模型，不声称跨进程数据库事务。

仅可编辑的 prompt/pure 显式文本预览具备更新能力，AI、网络、选区、活动文本等路径不扩权。未交付、失败或已离开运行的晚回执不能替换待保存配置。

## 旧自学习撤除

移除被动剪贴板和导航观察、习惯归纳、自动规则执行与建议、Learning Inbox、运行指纹和经验事件采集，以及相关设置、SDK 注册和原生命令。启动数据库时不再迁移或按日期清理旧学习事件。已有学习表和旧规则记录不永久删除；旧自动规则不再投影为可执行入口，旧开启配置被忽略。

手动保存工具、别名、固定、基础最近使用与浏览器历史排序保持可用。手动从浏览器导入参数属于用户明确动作，保留。`learnable` 契约字段仍用于限定手动保存参数，并不启动学习。独立“猜你想干”分支不属于本次撤除范围，后续单独集成。

## 验证

集中类型、架构、构建和关键逻辑检查；原生 UI 使用隔离 profile 与合成文本验证保存别名、改参交付、显式更新、同别名新材料、取消、另存和冲突保护，并检查旧学习入口消失。未使用真实历史或真实 API。

### 本次实测结果

2026-10-11 在 Linux X11 隔离桌面完成：保存带 `synthupd` 别名的合成 JSON 工具（缩进 2），改为 4 并交付；取消确认保持 2，重新明确确认后保留身份并更新为 4。同别名处理新合成材料采用缩进 4，复制至外部编辑器后读回全文一致。另存缩进 6 的独立工具，原工具仍为 4。确认期间注入合成的并发配置变更至 8，界面明确拒绝覆盖，并可返回另存。成功更新退出确认，避免原快照继续显示成待执行操作。

实际搜索 `learning` 无结果，设置不再有旧学习开关、规则或收件箱。独立的 Observation 本地录屏/OCR/按键记录实验仍保留、默认关闭；它不连接被移除的学习链，不能将此次撤除描述为所有行为采集均消失。

类型、架构、Web/原生构建及来源/快照/失败/晚回执/旧数据库保留检查通过。仅 Linux 原生环境验证，未运行真实 API，未读取用户密钥或真实历史。
