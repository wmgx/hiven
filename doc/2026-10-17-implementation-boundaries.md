# 实现边界（2026-10-17 文案重写时从 UI 移出）

这些内容原先以常驻说明写在界面里，按阶段 C 规则移出 UI。按插件组织；条目是实现事实，不是界面文案。
## line-tools
- 名单核对：每行一项；空白行忽略，重复项只保留首次原文；共同项采用左侧原文，各结果保持来源顺序；选项只影响比较键，不改输出；忽略大小写仅折叠 A-Z，其他 Unicode 精确比较；两侧合计最多 1 MiB、MAX_LIST_LINES 行。
- 提取链接/邮箱：每项一行，保序保重复；Markdown 提取目标而非标签/标题；预览后复制，不打开链接或图片；链接须含 http(s)://；邮箱支持 name+tag@example.com，须与前后文字以空格或标点隔开，不支持带引号或国际化地址。
- 提取去重：仅保留首次出现；链接按原文精确比较，邮箱域名忽略大小写、@ 前区分大小写。
- 清理行列表：顺序为去首尾空白、去空行、去重复行；默认仅去空行；全部关闭时原文不变；去重基于前两步结果，精确比较、区分大小写、保留首次出现、不排序。
- 重复行查找：点击行号或 Tab+Enter 定位原文；复制内容含全部分组与出现位置。
- 正则转义：输出正则模式，非 JS 字符串，不加引号、不二次转义、不执行；空输入不生成输出、不改剪贴板。
- 提取 URL：仅 HTTP(S)，一行一个，保序保重复，不打开链接或图片。
- Markdown 转纯文本：保留地址、任务状态、代码、引用定义；HTML 与实体保留原文，不加载或执行；输入最多 128 KiB，完整输出最多 512 KiB。
- 清理 AI 终端文本：默认仅处理完整纯线条 Unicode 盒框，两侧各去一个填充空格，其余空白与管道符保留；残缺、带标题、嵌套、代码围栏内、宽度不确定的框保持原样；可选同时拆除完整 ASCII 盒框。
- 撤销接续：恢复上次“继续处理”前的完整输入、操作与参数，仅一次；撤销前若输入已被手改，需确认替换。

## textDiff
- AI 解释：点击后才发送；只有一侧非空时作为粘贴 diff 发送，两侧均有内容时发送完整前后文本；只解释不执行；两侧合计上限 60,000 字符，超限不发送也不截断；超时 60 秒。
- 格式化：美化缩进，保留字段顺序，不排序 key。
- JSON 对比仅当两侧均为合法 JSON 时可用，否则回退文本对比。

## text-explode
- 选择方式：点击或拖拽选择片段，Shift 拖拽切换选中状态。

## unix-permissions
- 仅本地解析，不执行 chmod、不访问文件；输入 `Unix权限 755`、`权限解析 4755` 或 `rwxr-xr-x`，Enter 复制完整解释。
- r/w/x 对文件为读/写/执行，对目录为列出/修改条目/搜索；实际访问还受 ACL、挂载选项与系统规则影响。
- setuid/setgid/sticky 仅对受支持的可执行文件/目录生效，受系统规则约束。

## clipboard-history
- 保留期：1–12 个 UTC 日历月，默认 3；不限条数；收藏（固定）项免自动过期，手动删除仍生效。
- 旧历史在用户明确「纳入保留期」前受保护；纳入后从当天重新计算。
- 过期或手动删除的条目进回收区，可恢复 30 天后永久删除；恢复后保留期从当天重算，原固定/保护状态保持；停用记录不暂停清理。
- 不自动识别密码、token、私钥；隐私由暂停记录、删除单条、清空历史、关闭图片/文件记录控制。
- 文本合并最多选 CLIPBOARD_TEXT_MERGE_MAX_ITEMS 条；合并/对比/队列总文本上限 1 MiB（UTF-8），不截断，超限报错。
- 顺序粘贴队列使用加入时的完整正文快照，之后编辑历史不影响队列；目前仅 Linux X11 支持。
- 编辑历史正文只改历史记录，不改系统剪贴板；取消保留原文，失败保留草稿；正文受文本大小上限约束，不得与现有条目重复。
- 合并/打包复制不改变历史与选择；失败时选择保留。

## user-commands
- 每次运行都需确认；需要 shell.run 权限，启用开关只控制命令是否出现在 Launcher，不授予权限。
- 成功时结果文案仅为 stdout（并复制 stdout）；失败为「exit 码 + stderr」。

## color-tools
- 仅显式 sRGB 十六进制字面量触发，输出 RGB/HSL/OKLCH；不解析任意 CSS。

## crypto
- 无额外边界；SHA-1/256/512 通过 WebCrypto 计算。

## translate
- AI 术语表：最多 20 条，每侧最多 80 个字符（按码点计），不含换行/控制字符，同原词不可有不同译法；术语随原文发送给所选 AI 服务商，仅当目标语种与术语设定语种一致时发送，模型不保证完全遵循。
- 术语未保存前的编辑只在编辑器内，切换配置组或关闭窗口会丢弃。
- AI 就绪检查只读元数据，不发送翻译正文或术语；额度与请求成败以实际翻译结果为准。
- 配置检查超时或元数据不可用时，已明确选择服务商和模型仍可尝试翻译。
- 保存的术语与当前目标语种不同时不会发送（UI 不再提示）。

## ai-writing
- 仅点击“生成”才会把原文发送到界面显示的服务商和模型，编辑文字不发请求；摘要语言跟随原文，要点上限只是生成偏好，需用户核对结果。
- 不保证模型限制或剩余额度；配置检查通过不代表请求一定成功。
- 未完成的流式预览不可复制或继续处理；停止或出错时原文保留。

## qr-code
- 识别支持 PNG / JPEG / WebP；有原生剪贴板图片读取时可用 ⌘V / Ctrl+V 读取已复制图片，否则走粘贴/拖入/选择文件。
- 复制与保存成功不再提示（复制后窗口随 host.complete 关闭）。

## regex-tester
- 提取：取全部匹配的完整文本（最多 MAX_REGEX_MATCHES 条）按顺序换行连接，保留重复与空白；高亮仅用于定位。
- 零长度匹配无可提取内容；所选捕获组缺失/为空字符串时不提取；超过条数上限或提取内容超过 1 MiB 时不提取。
- 执行超过 1 秒终止；AI 候选需通过全部正反例，描述 1–4,000 字符，例子合计最多 12 条、每条 ≤4,000 字符，仅发送描述与例子，在隔离限时执行器中校验；候选通过不保证适用于其他文本。
- 正例要求至少一处匹配，反例要求无匹配。

## csv
- 筛选（文本/SQL）与列排序先作用于完整结果，再截取预览行；复制与另存使用完整结果。
- 另存完整结果上限 10 MiB；带回搜索上限 1 MiB，超限时在对应错误提示中给出。
- 带回搜索需先「处理完整文件」。
- Markdown 输出：单元格按纯文本，换行转 `<br>`，HTML/Markdown 语法转义；JSON 仅接受对象数组，列按对象键首次出现顺序，缺失值/null 留空，嵌套值用紧凑 JSON，保留空键与含空格键；CSV 多出字段自动补列名。
- 列统计：统计筛选和转换后的全部结果行（不取预览）；空值和纯空白不计为 0；仅接受十进制/科学计数法，最多 100 位有效数字，指数绝对值 ≤1000，最多 512 字符；无效或超范围值不参与求和/平均；求和精确，均值最多 20 位有效数字（四舍五入近似，UI 以 ≈ 标记）；去重按非空单元格原始字符串，区分大小写和空格，1 与 1.0 不同；JSON 缺失/null 视为空。
- 源文本过大（编辑器卡顿阈值）时默认锁定编辑，需点「仍要编辑」。
- SQL 过滤器解析错误信息（csvSqlFilter.ts）为英文技术文案，未改动。

## json-tools
- 字段路径（JSONPath/JSON Pointer）查找上限 1,000,000 字符、128 层嵌套，不截断；重复键 JSON 不复制路径。
- 类型推断上限：128 KiB UTF-8 输入、64 层嵌套、20,000 节点、512 KiB 输出；不抽样不截断；重复键 JSON 不推断；推断类型只描述样例，不代表 API 契约。
- URL 参数编辑：纯本地，不访问 URL；修改签名 URL 会使签名失效；未修改部分保留原编码；无效百分号/UTF-8 编码按原文显示，编辑后按文本重新编码。URL 上限 262,144 字符、1,000 个参数。
- 表达式不会自动运行，需手动执行（⌘/Ctrl + Enter）。
- 「替换输入」保留当前操作与参数并即时重算；反向操作（如 YAML→JSON 结果替换输入）会切换为反向操作；表达式模式保留表达式，手动执行后更新。

## curl-inspector
- 仅本地解析：不发请求、不执行命令、不读文件、不自动读取剪贴板；须在工具内粘贴，初始文本被有意忽略。
- 支持 POSIX 引号、反斜杠续行，以及 URL、-X、-H、-d、--data-raw、--url、-I；最多 100,000 字符。
- 请求头展示显式请求头及数据默认内容类型，不模拟传输层自动生成的请求头。
- 复制不写入 Hiven 历史（recordInHistory:false），失败时不回退为普通复制；剪切被禁用。
- 不支持：Shell 展开/运算符/多命令、别名/赋值/包装命令、@file、多 URL、删除请求头/空请求头简写、重复方法、--head 与数据或方法组合、URL 通配展开。

## formatter
- CSS 压缩：收紧结构空白，保留注释和值，自定义属性与转义语法不变。
- SQL 压缩：只收紧字面量外空格，保留注释与换行。
- XML 格式化/压缩保留正文及空白；不支持含 DTD 的 XML；无 XML 解析器的环境报错。
- 失败时输入保持不变。

## file-paths
- 仅做字符串转换：不读文件、不检查存在性、不展开 shell 变量、不解析符号链接。
- 相对路径输出使用 /；Windows 比较忽略大小写；`//server/share` 与 Windows 相对路径需手动选 Windows 语法。
- 相对路径必须显式提供绝对基准目录，不猜测项目/工作目录。
- 输入须每行一条不带引号的路径，不含空行/控制字符；file URI 不支持查询、片段或编码后的路径分隔符。
- Windows 盘符相对路径与无盘符根路径有歧义，需补全盘符或 UNC。
- 上限：输入 1,048,576 字符、10,000 条路径，基准目录 32,768 字符；Markdown 图片输出 1 MiB（UTF-8）。
- Markdown 图片模式：路径指向目录时报错，不读取文件。
- 从文件管理器「复制路径」后粘贴文本；不读取文件管理器剪贴板元数据。

## encode-decode
- 图片 Base64：支持 PNG、JPEG、静态 WebP；最大 10 MiB，单边 8192 像素、总计 1600 万像素；data URI 保留原始字节，复制图片与另存统一为 PNG；仅在用户明确选择时读取剪贴板/文件。
- 图片缩小：保持比例与透明，不放大，不保证文件大小；输出高度按像素四舍五入，需不小于 1 像素。
- 图片遮挡：实色矩形，Esc 取消当前拖动，Ctrl/⌘ Z 撤销；替换图片会丢弃未复制/未保存的遮挡。
- 裁剪：可拖框或输入原图像素坐标与尺寸，需为图片范围内的整数。
- URL 解码：`+` 保持不变；URL 编码：空格 → %20，`+` → %2B。
- 「替换输入」会把当前结果作为输入，并自动切换为相反方向后重算。
- 失败时输入与已有选区/遮挡均保留，可重试。

## calculator
- 变量：`a=1` 回车保存，之后可用 `a*a`；变量名为英文字母、数字或下划线，不以数字开头；关闭后清空。
- 函数：乘方（整数指数，`^`/`**`）、`sqrt`、`abs`、`round`/`floor`/`ceil`。（界面上的语法提示 Tooltip 已删除）
- 单位换算：最多 12 位有效数字，`≈` 表示已舍入；KB = 1000 B，KiB = 1024 B，b = 比特，B = 字节；单位符号区分大小写；量级范围 −30 到 30。
- 中文大写：整数大写不带货币单位；金额大写精确到分，最多两位小数不自动舍入；整数部分最多 16 位（最高兆）。
- 进制：支持 0xFF、`255 to hex`、`bin 1010 to dec`；最多 256 位输入数字；负数带符号，不使用补码。
- 千分位：英文格式（逗号分组、点号小数），保留全部数字与尾零；输入已含逗号视为歧义报错；最多 10,000 字符，不截断。
- 批量计算公式：逐行计算，遇到第一行非公式停止；多行结果先预览，不直接覆盖编辑器。
- 求和使用 BigNumber 高精度。历史本地长期保存，点击算式或结果可继续计算；Enter 保存并继续，↑↓ 翻历史，⌘/Ctrl+Shift+C 复制结果。
- 直接答案（千分位/大写/进制/单位）副标题已删除，Enter 复制答案。

## date-time-assistant
- UTC 偏移支持 UTC、UTC+8、+05:30 等数字偏移；输入内容自带的偏移优先。
- 示例输入：now、1781064306、2026-06-10 12:05:06、2026-06-10 12:05:06 UTC+8。
- 时区转换：支持 EST、UTC±偏移、IANA 时区；其他缩写有歧义；区分固定偏移与按日期的时区规则；回车复制。
- Cron：仅标准五字段（分 时 日 月 周），不支持秒、Quartz 符号、宏、附加字段；仅预览，不创建任务；日期与星期均非 `*` 开头时满足其一，否则须同时满足；DST 空缺跳过、重复各算一次；向后查找八年。
- 复制 Cron 结果的文本不再附带日期/星期规则说明，只含表达式、描述与下次时间。
- 相对时间：仅支持非负整数天/小时/分钟（上限 3660 天、87840 小时、5270400 分钟）；不支持月/年；日历天保留当地时分秒，精确时长按小时/分钟；回车复制基准与结果（复制文本不再附带规则说明）。

## random
- 长度需为 1–1024 的整数；数量 1–100；字节数 1–1024。
- 密码为高强度（含大小写、数字、符号各至少一位）；UUID 为 v4；颜色为 #RRGGBB。

## web-open
- 快开规则无需扩展即可使用；连接配套扩展后可搜索 Chromium 浏览器的实时标签和历史并聚焦已打开页面（扩展向 Hiven 的 `browser.chromium` 目标源推送，沿用 Desktop Target 协议）。
- 扩展无法静默安装：位于插件目录 plugins/builtin/web-open/extension，需在 Chrome / Edge 扩展页开启开发者模式后「加载已解压的扩展程序」；更新后需重新加载以授予「历史记录」权限。
- 标签搜索：空搜索不展示标签，输入标题或 URL 片段匹配；断连时静默无结果，不影响其它搜索。
- 浏览历史：原始 URL 只留在本机；Launcher 历史范围可选天数或全部。
- 自动关闭不活跃标签：固定标签、正在播放声音的标签、窗口中的最后一个标签不会被关闭。
- 规则：`{query}` / `{clipboard}` 会被输入或剪贴板内容替换；匹配「快捷匹配正则」时跳过二次输入直接打开；「记录参数历史」成功打开后记住参数。
- 网站图标缓存：插件内部缓存，供启动器结果列表使用，可单独删除或全部清空；使用快开规则后自动写入。
- 从浏览历史导入参数：读取浏览历史，为已开启「记录参数历史」的规则导入匹配参数。

## 宿主（设置、固定项、AI 服务）
- 固定项：记录保留到用户明确取消；此处不能直接执行入口；应用可用性仅对应用扫描结果有效，其他类型入口无法确认。
- 快捷应用别名：最多 10 个，每个不超过 80 字符；修改保存后才生效；保存空列表恢复按原名称与别名搜索；切换应用会放弃未保存的修改；不能填写文件路径、内部应用 ID 或网址。
- 猜你想干：默认关闭；仅在全局启动器空闲时最多显示三条；本地记录成功静态动作标识、来源应用标识、时间和会话，最多保留 90 天、1000 条；不读取正文、剪贴板、标题、网址或路径；开启期间暂停自动附加剪贴板；清除只移除该功能的记录和计数；建议不会自动执行。
- Jev 命令推荐：仅在本地搜索无匹配时，将输入框内容和命令说明发送到 Jev，不做过滤或脱敏；推荐命令；输入是待处理内容时选中后原样带入；不接入剪贴板与编辑器内容；推荐不会自动执行。接口地址须为完整 `/v1/systemone` 地址，本机测试可用 HTTP；密钥仅保存在本机应用设置。
- Ollama：文本发送到 127.0.0.1:11434 的本机服务，排除标记为云端的模型；被修改的本地服务仍可能转发文本；所选本地服务或模型不可用时停止，不自动切换；传输上限 256 KiB（UTF-8）。
- AI 默认服务/模型/推理强度：插件未指定时使用；插件可在单次请求中覆盖。
- 登录链接复制：复制后进入系统剪贴板；Hiven 会话不记录该链接，其他剪贴板应用仍可能读取。
- 双击修饰键全局快捷键仅 macOS 支持，需要辅助功能权限。
- 应用快捷键：应用已在前台时再按一次可隐藏（macOS）。
- 窗口交接上限 10 MiB；材料对比合计上限 1 MiB；文件读取为文本上限 1 MiB，须为普通 UTF-8 文本文件。
- 粘贴可用性预检只是预检，不保证之后的粘贴成功；预检结果未知时仍保留尝试路径。
