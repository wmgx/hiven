# 截图存为文件快捷键

`encode-decode` 插件的“截图存为文件”动作支持在快捷键设置中显式绑定全局快捷键。该动作默认不绑定，也不会出现在 Launcher 列表中。

触发后沿用现有保存链路：读取剪贴板图片、打开原生保存对话框、保存 PNG、将绝对路径写回剪贴板，并在原前台应用上显示固定结果 HUD。快捷键入口不会显示或激活 Launcher / 主窗口。

边界约束：

- 插件或动作禁用、快捷键未绑定、缺少既有剪贴板或文件权限时，在读取剪贴板前终止。
- 同一保存动作串行执行；已有保存流程未完成时忽略重复触发。
- 用户取消保存时不改写剪贴板，也不显示重复提示。
- 动作执行期间目标失效时不显示迟到反馈。
- 文件保存成功但路径复制失败时，明确提示“文件已保存，但路径复制失败”。

## 验收记录

Linux 原生端使用隔离的 Xvfb / xfwm4、Tauri AppImage、WebKitWebDriver 与合成 PNG 验收。验证了外部应用获得焦点时直接打开原生保存对话框、Launcher / 主窗口不闪现、取消不改写剪贴板、成功保存的像素与源图一致、绝对路径可粘贴回外部应用，以及固定 HUD 显示在原目标上。

macOS 实机尚未验收。
