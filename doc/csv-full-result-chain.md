# CSV 全量筛选、排序与结果交付

## 用户行为与范围

此前表格的筛选和排序只作用于截断后的预览，完整输出仍来自未筛选的表。现在处理顺序为：解析完整源文本 → 去空行/去重/转置 → 文本筛选或既有 SQL WHERE/ORDER BY/LIMIT → 表头排序 → SQL 列投影 → 序列化。表格和输出预览分别在最终结果上截断，不再改变完整结果。

小表同步更新；需要全量解析的大表保留现有“处理完整文件”、进度和取消。修改源文本、解析/变换/输出参数、筛选条件或排序会撤销旧结果身份，必须重新处理后才能交付。无效 SQL 显示错误且不能交付旧结果，合法零行仍为有效结果。原控件在这些状态下保留，可原地修改。

完整结果复制、带回搜索和下载使用同一份当前结果。明确标注“复制原始源文本”的来源视图和“复制选区”的局部复制保持原合同。带回搜索仍受既有 1 MiB UTF-8 上限及回执保护；另存通过现有材料入口完成。本批不改变浏览器下载在桌面环境中的支持限制，也不添加文件权限或新的保存接口。
