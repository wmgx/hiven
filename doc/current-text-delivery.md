# 当前文本的直接交付

从历史带回文本并确认编辑后，材料会变为当前输入。复制、粘贴推荐现在依据当前完整文本而不是历史来源提供；仍使用原有推荐行和搜索过滤，不增加常驻按钮或材料菜单。输入来源标为「输入」，不再误称剪贴板。

交付只读取本次材料的完整 `payloadText`，不回查旧历史记录、不使用截短预览，不隐式读取剪贴板或文件。敏感/隐藏正文与图片、文件对象不走这条文本路径；历史媒体保留原有权限和私有资源路径。

推荐行绑定材料代际和当前根会话。重复交付在途互斥，旧行和迟到完成不能清掉新任务。粘贴复用既有权限/可用性检查与目标窗口逻辑；已发出的外部复制或粘贴不可撤销。原生自行关闭窗口后的仅复制反馈保留，重开或换材料后不显示旧反馈。

手动编辑继续按原规则替换当前材料，不新增恢复栈或持久草稿历史。原历史记录不受编辑影响，仍可显式重新取回。
