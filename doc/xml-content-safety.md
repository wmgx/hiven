# XML 内容安全与 CSV 预览范围

XML 不再使用 trim 和全局空白替换排版。词法扫描保留原始片段，标准 DOMParser 只负责验证，不将 DOM 重新序列化。DTD/实体声明在调用解析器前拒绝，不读取外部实体或网络。无效输入保留原稿并禁用交付，XML 命令入口同样返回本地化错误。

格式化只为没有文本/CDATA 子节点的纯标签结构补缩进；混合文本、已有空白、CDATA 与 xml:space 子树保持原文。压缩仅清理根元素外部的结构空白，根内可能保持不变，以免改变正文含义。此策略优先保内容，不承诺所有合法 XML 都会产生更短结果。

CSV 的表格排序与筛选仍只改变预览。原有提示明确输出使用整理后的全部数据和顺序；复制名称区分选区、原文、预览输出与完整输出，不新增数据排序或筛选转换。

## 验证边界

Node 实际词法模块检查覆盖基本缩进、mixed content、空白分隔、CDATA、实体原写法、xml:space、带引号属性、声明及 DTD 拒绝。Node validator/DOMParser 明确为注入或 mock，不作为原生语法验证证据。独立审查未发现阻断，源码释放检查通过。

保守限制：合法数据若使用 Mozilla/XHTML 命名空间中的 parsererror 元素，会被当前原生错误检测保守拒绝；没有因此放松错误校验。SQL/CSS 算法未纳本批。

末版 `93ed603` 的实际 npm 测试入口、类型检查、Vite 构建和官方 AppImage 打包均 exit 0。新 Linux X11 QA 实例验证：基本嵌套正确缩进；错配 XML 和重复属性均显示中文错误并禁用交付，修正后恢复；重复属性实际经过 Tauri 的标准 DOMParser 拒绝。混合输入 `<p>甲 <b>乙</b> 丙</p>` 经格式化后复制到新 Mousepad，精确保持原 19 字符及两处空格，无新增换行。界面仍显示「输出已就绪」，不声称另有保原文提示。

CSV 人数排序后的原提示位明确显示「排序/筛选仅影响预览」，复制名称为完整输出；本次只核说明，没有重复上一轮已验证的 CSV 解析/输出全链。CUA 一次挂起经标准会话重置恢复，Hiven 进程未因此重启。
