# xAI 原生流与取消约定

## 请求生命周期

- `ai_xai_response_stream` 在认证、输入转换和第一次异步等待之前登记 run ID。
- 同时运行的重复 ID 被拒绝，不能替换原请求，也不能清除原请求的登记。
- 取消先于登记到达时，保留最多 256 条、60 秒有效的取消记录；消费后移除。ID 最长 128 字节，过期记录在下一次登记或取消时清理。
- 取消会唤醒并丢弃推理请求的 future，包含尚未返回响应头的 `send()`、等下一段响应的读取和 HTTP 错误正文读取。登记 guard 在成功、失败、取消以及命令 future 被丢弃时清理。
- 收到 `hiven.cancelled` 表示本地请求已结束。断开 HTTP 连接不能证明服务端已经停止计算或计费，不应在 UI 作此承诺。

## SSE 解码与结束条件

- 先按字节形成完整行，再验证 UTF-8；中文和 emoji 的字节可以跨任意网络分段。
- 支持 LF、CRLF、独立 CR、开头 BOM、注释和同一事件的多行 `data`。
- 同一事件最多积累 8 MiB，畸形 UTF-8、JSON 或无类型事件明确报错。
- EOF 前最后一个完整 JSON 事件即使没有换行或空行，也会解析；不完整 JSON 报错。
- 只有 `response.completed`、`response.failed`、`response.incomplete`、`error` 结束本次流。首个终态之后不继续发 delta，也不等待服务端关闭连接。
- 没有响应终态就 EOF，或者只收到 `[DONE]`，均不能视为成功。
- 前端事件通道关闭时结束请求，避免无人消费的推理继续留在本地。

## 认证刷新边界

等待刷新锁可以取消。已取得锁、准备轮转 token 的刷新任务独立完成，网络请求限制为 30 秒；取消推理不会在 token 已轮转时截断本地持久化。

刷新结果在落盘前重新比较当前登录凭据，并与登录写入、退出删除使用同一文件锁。用户已退出或更换登录时，旧刷新结果不能复活或覆盖会话。凭据格式、登录入口和存储权限保持原样。

## 本地回归

从配置好 Rust/Tauri 依赖的环境运行：

```bash
cargo test --locked --manifest-path src-tauri/Cargo.toml --lib ai_xai::
```

测试直接执行生产模块，涵盖：

- 每个 UTF-8 分段位置及逐字节输入、CR/LF/CRLF、多行事件、完整和畸形 EOF
- 缺终态、重复终态后的事件隔离、通道失败、事件大小上限
- 登记前取消、取消记录限额与过期、重复 ID、失败和 future 丢弃后的清理
- 本地 HTTP 服务器停在响应头或响应正文时，取消请求，并由服务器确认客户端连接已断开
- 临时目录中的假 token 轮转提交，以及退出或更换登录后拒绝旧结果

测试只访问 loopback 和隔离临时文件，不登录真实账号，不调用付费 AI，也不使用真实凭据。生产服务的取消计费行为与桌面 IPC/UI 旅程需分别验证，不能从这些测试推断。
