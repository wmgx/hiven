# 历史按月保留与分页界面

插件设置 version 2、clipboard-history 2.0.0，复用原设置 schema。保留月数 1–12，默认 3 个 UTC 日历月；旧最大条数、保留天数、总缓存限额不再出现在 UI，也不作为新清理策略。单项文本/图片大小限制仍保留。

设置迁移只合并默认值及规范化月数，保留用户录入开关/大小等偏好，不读取、过期或删除历史，不自动启用旧记录按月清理。存储层旧记录默认受保护，UI 明确显示数量；“将旧记录纳入保留期”必须在原 Dialog 中再次确认，并明确从今天重算周期。固定（收藏）项免自动过期，但手动删除仍然有效。

回收区统一显示自动过期和手动删除条目，30 天内可恢复，之后后台自动永久清理。恢复从今天重算周期，保持原收藏/保护状态。回收区仅预览与恢复，不提供历史复制、粘贴、编辑、Diff/队列或收藏操作。详情显示恢复截止时间。停用新记录只影响后台监听，不暂停既有历史维护，也不阻挡历史浏览、手动删除、回收区恢复或显式复制/粘贴。状态区与设置文案明确说明。

历史列表只持有当前页，最多 100 个轻量条目和单个选中正文；前后页保存游标而非累积所有历史。全文搜索在仓储分页运行，空匹配扫描页会继续推进直到找到结果或穷尽，期间显示进度并允许改查询取消。旧查询、窗口 owner 变化和晚回执不能覆盖当前结果。

跨搜索/跨页多选仍按独立 ID 队列及选择顺序保存，完整快照按 ID 读取，不依赖当前页。搜索命中定位在当前选中全文上运行。返回设置或 Diff 保留查询、当前游标及有序选择。

逻辑验证：`node scripts/test-history-month-settings.mts`、`node scripts/test-history-page-reader.mts`，只用合成内存数据，不读取用户历史。仓储事务/迁移/清理由存储测试覆盖；真实原生分页、搜索、恢复与确认取消由本轮集成验收负责。
