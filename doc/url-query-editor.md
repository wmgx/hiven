# 完整 URL 参数编辑

复用 JSON Tools 的 Query 分组，新增“编辑完整 URL 参数”操作；没有独立插件或常驻启动入口。原输入编辑器接收完整 URL，参数按原始顺序逐行编辑、添加或移除，完整结果仍用原输出区复制／继续处理。参数变化同步回完整输入并沿用未保存变更与交付生命周期。

## 无损边界

- 仅接受完整 HTTP(S) URL；不访问 URL，不请求网络。原文含未编码空白或控制字符时明确拒绝。
- 只按第一个 `?`（位于 `#` 之前）分离查询，保留地址主体和完整 fragment。每个参数按第一个 `=` 分割，不转为对象，重复键、空键、空值、无等号标记和空参数段均保持顺序。
- 编辑字段时，只重新编码那个名称或值。未修改字段沿用原始字节字符串，包括 `%2f`／`%2F`、`+`／`%20` 差异；相同解码值的无操作编辑不重写编码。新增／修改字段用百分号编码，空格为 `%20`。
- 无效百分号／UTF-8 编码按原文显示并明确提示；未改字段仍原样保留，用户编辑该字段后按普通文本编码。
- 删除最后一个参数保留原有 `?` 查询标记；不替用户规范化路径、端口、主机大小写或锚点。
- 始终提示修改签名 URL 可能让签名失效。不会自动打开、验证服务器签名或修复签名。
- 最多262,144个 UTF-16 字符、1,000个参数。超限或不完整 Unicode 字符明确拒绝，不截断或写入部分结果。
