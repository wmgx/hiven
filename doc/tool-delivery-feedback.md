# 工具结果交付反馈

## 问题与范围

此前 URL 工具的真实失效目标验收已证明：窗口、输入与结果能够恢复，但自动粘贴失败提示会短暂出现后消失。根搜索材料和剪贴板历史已有持久反馈，工具页面仍仅调用默认 3.5 秒通知。

本批让文本工作台、原文本整理、编解码和格式化使用同一份反馈生命周期，并在各自原有结果状态区域展示。剪贴板写入成功而自动插入失败时，可停留阅读“已复制但未插入”的说明；写入失败显示失败，不承诺可手动粘贴。没有新增工具栏、恢复按钮或自动重试。

## 生命周期

反馈同时绑定当前宿主会话、输入及操作产生的结果身份和本次交付。更改输入、替换输入、切换操作、下一次交付以及离开都会清除旧反馈。异步结果过期后不能关闭新页面或覆盖新状态；原有正文和未提交修改标记保留。

宿主只公开当前 surface 的只读有效性与失效订阅，复用既有粘贴恢复 owner。普通重渲染不创建新会话；真实隐藏、重新唤起、插件或权限失效会撤销旧 owner。预期的粘贴临时隐藏沿既有合同保留 owner。带回搜索主动撤销旧交付尝试，拒绝或失败留页后仍可重新操作。

没有改变原生目标校验、窗口恢复、剪贴板权限、成功交付或带回材料的数据合同。没有记录正文、窗口标题或目标身份。
