# 浏览全部动作：工具发现与明确分类

## 用户效果与边界

沿现“浏览全部动作”入口、搜索框和列表，让工具先于维护/系统动作出现；同一导航行可筛选全部、工具、应用与窗口、系统。没有新主页、卡片、层级菜单或任务分类框架。

分类只读取现有稳定systemKey、pluginId、productProvider与桌面能力元数据。工具沿产品catalog顺序相邻，未知候选保留在全部。上游availableItems继续负责插件启用、权限与能力可用性，分类不新增权限或执行动作。

筛选只作用于空查询的浏览态。开始输入立即退出浏览、使用原全局搜索排序；清空回原推荐，不保留隐藏范围。Esc或可见返回退出浏览并聚焦搜索。分类控件不进入结果数组，上下键、数字快捷键与执行仍指向同一批可执行候选。
