A+ 相对 A 的改动

  • 设置/插件图标 → lucide 线标 + 淡底
  • 插件 hover 仅淡底；只有展开才抬卡
  • 行上只留 名称 / 描述 / 来源 tag / 必要控件
  • 版本路径进「关于」行，不污染列表
  • 关于区做成产品条，与表单组分离
  • 统一控件厚度 + 可见 focus ring

交互说明

  • 点插件行主体 → 展开/收起（同时仅一行）
  • ⚙ / ⋯ / 开关 不触发展开
  • 顶栏可切「空态 / 错误条」看状态
  • 键盘 S 设置 · P 插件

刻意没做的

  • 无全大写 eyebrow
  • 无每行默认浮卡
  • 无灰底大容器铺底
  • 无粗左侧 accent 色条
  • 无能力 chip / 路径堆在主行
