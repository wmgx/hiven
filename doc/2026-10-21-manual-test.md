# 2026-10-21 整改桌面手测清单

来源：批次 1-5 修复报告的「需要人工验证」，加收尾批次（批次 6）新增项，已去重合并。
范围：只列无法靠单测或 web 验证覆盖的点（桌面窗口生命周期、原生能力、跨窗口、键盘/输入法、真实浏览器扩展）。
约定：「设置 → 插件 → 浏览器」指设置页里的浏览器插件设置卡片；按钮名以界面实际文案为准（中文界面为「打开扩展目录」，英文界面为 Open extension folder）。

## 必须测

### 1. 浏览器扩展 token（两步操作，升级后必须先做）

背景：本地 bridge 现在要求 `Authorization: Bearer <token>`，旧扩展（0.3.8）会被 401 拒绝，标签和历史都不会出现。

1. 升级并启动 Hiven，打开 设置 → 插件 → 浏览器 → 浏览器连接。若扩展仍是旧版，卡片顶部会出现黄色提示「浏览器扩展版本过旧或缺少授权文件……」（最多约 2 分钟内出现，旧扩展每次轮询都会触发）。
2. 第一步：点「打开扩展目录」。预期：弹出 Finder，目录里有最新扩展文件和 `bridge-token.json`。
3. 第二步：在浏览器打开 `chrome://extensions`，找到该扩展，点「重新加载」。预期：扩展版本由 0.3.8 变为 0.4.0。
4. 回到连接卡片，等待数秒。预期：状态变为「已连接」，黄色提示消失；launcher 里能搜到标签页和历史。
5. 反向验证：在任意普通网页控制台执行 `fetch('http://127.0.0.1:19246/v1/sources/browser.chromium/targets')`。预期：被拒绝（CORS 或 403），拿不到数据。
6. 若扩展目录已存在，重启 Hiven 后 `bridge-token.json` 应被自动刷新（无需再点按钮），重启后连接保持正常。

### 2. 敏感内容与输入劫持

1. 在 launcher 输入 `1password`、`visualstudiocode`、`select one from the list`，停顿 1 秒。预期：输入框内容不被清空，不挂 Block。
2. 输入合法 JSON、URL、时间戳后停顿。预期：仍会挂 Block；按 ⌫ 或点 x 移除后，文字回到输入框，且不会再次自动挂载。
3. 复制一段密钥形态文本（如 `sk-` 开头的长串）再唤起 launcher。预期：被识别为敏感，退出后重新打开 launcher，该 Block 不残留（可到开发者工具看 localStorage 无明文）。

### 3. Esc 与返回行为

1. 文本输入类命令输入内容后按 Esc。预期：直接返回，没有「放弃修改」弹窗。
2. 根帧有输入或 Block 时按一次 Esc 只清空，空根帧再按一次才关闭；根帧底栏显示「关闭」，浏览全部动作时显示「返回」。
3. 设置页里打开 AI 默认模型下拉，按 Esc。预期：只关下拉，不退出设置页。

### 4. 语言切换

1. 不重启，切换界面语言后立刻唤起 launcher。预期：错误提示、插件文案、行右侧类型标签（应用/窗口/浏览器/文档/会话/联系人、「最近访问」等）均为新语言。
2. 中文界面下进入 设置 → 插件 → 浏览器 → 快开规则。预期：三条默认规则显示中文名（Google 搜索、GitHub 仓库、MDN 文档），选中后「名称」和「占位提示」输入框也显示中文；把名称改成别的文字后保持用户输入原样，不再随语言变化；切回英文界面显示英文默认名。

### 5. 剪贴板（原生）

1. 复制文本、复制图片、再复制同一段文本。预期：历史各出现一条（同文本去重规则按现状）。
2. launcher 隐藏、空闲时观察活动监视器。预期：CPU 安静，不再持续轮询剪贴板。
3. 复制超限大图后保持空闲。预期：不反复编码（CPU 不持续占用）。
4. 剪贴板历史里图片的保存和预览正常；升级前就存在的老图片仍能读取（旧 `.json` 元数据兼容）。
5. 剪贴板历史组装文本（合并）后复制，以及 cURL 解析里的复制。预期：这些复制动作不会作为新条目回灌到历史（本批把权限改为 manifest 声明的 `clipboard.history`，需确认行为未变）。
6. 一次外部复制仍能被历史捕获；剪贴板历史设置页的权限列表里出现「复制时不写入剪贴板历史」，且默认已授予。

### 6. 剪贴板历史回收站

1. 打开回收站，选中一条，点「彻底删除」。预期：弹出确认框「彻底删除？该项将被永久删除，无法恢复。」；点取消，条目仍在；再点「彻底删除」并确认，条目消失。
2. 点「清空回收站」。预期：弹出带数量的确认框；确认后清空；确认框打开期间键盘快捷键不触发其它操作。
3. 滚动加载：列表滚到底自动追加；搜索和筛选后重置到顶部；复制新内容后刷新，保持已滚动的深度。

### 7. 窗口与进程（macOS 辅助功能权限）

1. 对同一 App 的两个同标题窗口执行「关闭窗口」。预期：只关目标窗口（需已授予辅助功能权限）。
2. 切换窗口、结束进程的命令正常列出且不卡主线程（列表由后台线程生成，AX 线程安全性未在真机验证过，请留意是否崩溃或结果为空）。

### 8. 更新与权限（launcher 窗口内）

1. 设置页检查更新、下载、重启。预期：updater/process 权限仍可用。
2. 设置页按钮显示「更新到 vX」。
3. 在插件窗口授权或撤销权限后，设置窗口的权限列表即时刷新，且两边互不覆盖。

### 9. 应用索引

1. 安装一个新 App，10 分钟后重新唤起 launcher。预期：可搜到（首次唤起后等待后台扫描完成）。
2. 删除或移动一个已缓存的 App 后唤起。预期：该 App 的启动目标失效并重新发现，不报错。

### 10. 插件版本加载

升级后确认释放目录加载到最新版本：web-open 1.13.3、clipboard-history 2.1.2、curl-inspector 1.1.1。在插件页能看到对应版本号，且功能（上面各项）均为新行为。

## 建议测

### launcher

1. 参数页提交失败后输入框自动重新聚焦，Enter 可再次提交。
2. 编辑器内命令入口输入宽泛关键字。预期：可滚动并用键盘到达第 12 条之后的项。
3. 生产构建里搜「控制台/devtools」搜不到；dev 构建仍可用。
4. 剪贴板历史项的粘贴、复制、打开到快捷编辑器，以及提示语言（中英文）；点击不存在的 surface 时的 toast 文案。
5. 上下文建议（已开启时）首帧展示与之前一致，无闪烁；启动日志中不再出现无谓的前台 App 查询。
6. 对象列表删除条目：第一次点击变成「再点一次确认删除」，失焦复位，第二次才删除。

### 插件

7. image-tools 的四个路由（缩放、裁剪、涂抹、存 PNG），尤其「剪贴板图片保存」流程；绑定到旧 encode-decode 图片保存的快捷键不会自动迁移，需要重新绑定。
8. line-tools 的 launcher 入口缩减为 16 条精选，确认符合预期；SQL IN 对反斜杠的转义偏 MySQL 风格。
9. calculator 中 `10-5-2` 这类三段以上破折号数字不再计算；日期、手机号不被当作算式。
10. regex-tester 现在只能从 Global Launcher 进入，编辑器内命令面板不再有入口。
11. color-tools 的 CSS 颜色名（red、tan、gold）作为普通结果展示，不抢排名。
12. JsonSurface 输入超过 20 万字符时出现手动「运行」；普通输入下 `useDeferredValue` 的输入手感无明显延迟。
13. csv 的「推断数字/布尔」开关（默认关）；把 columns、keyed、ndjson 输出粘回输入仍可解析。
14. text-diff 单一入口：JSON 输入自动进入 JSON 模式；AI 解释按钮在无 AI 时点击后才提示不可用。
15. web-open：输入内网 URL 时不应触发 favicon 请求；launcher 里默认规则仍按 locale 显示。
16. user-commands：执行成功后出现「复制输出」，且剪贴板未被改写。

### HUD 与设置页

17. 文本结果 HUD：Enter 复制，Shift+Enter 粘贴（仅在可粘贴且未复制过时）；输入法组合态 Enter 不触发。
18. 插件行内开关可用键盘 Tab + 空格启停，且不展开抽屉。
19. 中文界面下已停用插件的状态点不是绿色。
20. 设置页：「保留参数」已消失，上下文建议计数文案为「展示 N 次 · 选用 N 次 · 成功执行 N 次」。
21. AI 设置页：改 endpoint 后 key 保留（但「启用」会关闭，需要重新保存）；切 Tab 不丢草稿。
22. 剪贴板年龄追踪：launcher 隐藏时不再有 `clipboard_read_public_text` 轮询，唤起后首次的「新旧」判断正常（依赖 WKWebView 失焦/隐藏事件）。

### 原生

23. 插件页「监视开发插件」按钮：修改开发插件文件后能自动重载（fs watch scope 生效）。
24. 从 GitHub 目录安装插件（含带 `/` 的分支，如 `?ref=feature/x`）。
25. 安装插件 zip：超大或条目过多的 zip 被拒绝，提示合理。
26. 在 Finder 中显示（reveal）只限 `~/.local/hiven` 下路径，其它路径被拒绝。
27. 一次运行带 Codex 的 AI 流程：Codex 线程只读、不弹审批。
