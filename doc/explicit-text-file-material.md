# 显式添加文本文件

Launcher 根搜索栏提供低权重的「添加文本文件」图标入口，已有材料时提示「更换文件」，不再为文件导入占用结果列表的固定一行。用户不必先复制路径或等待剪贴板材料出现。在原生单文件选择框选定文件后，直接按文本读取并成为当前材料，不自动运行工具、复制、粘贴或发送给 AI。

读取复用现有原生限制：普通本地文件、最大 1 MiB、严格 UTF-8，拒绝二进制控制内容。格式仍为已有文本白名单，不开放目录或批量读取，也不改变普通查询文字的路径处理规则。

选择和读取期间保留原材料、搜索内容及已有恢复状态。取消或失败不替换原稿；成功后可恢复前一份材料。文件正文使用 `file-content` 标记，即使内容恰好是另一个文件路径，也只作为字面文本处理。

原生选择框会暂时取得焦点，活跃期间用会话内生命周期保护避免 Launcher 因失焦或后台空闲而误关。取消旧结果与关闭原生选择框分开处理；选框结束后恢复正常关闭行为。关闭、换材料或离开本次根列表后，迟到结果不能覆盖新的任务。

验证以正式构建的真实原生选框和合成文件为准；受控回归另覆盖延迟选择/读取、失败保稿和焦点生命周期，不以这些回归代替真实界面验收。
