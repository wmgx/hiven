# 操作范围与错误归属

本批沿用既有界面，不添加操作入口或更改文本算法。

- 根查询发生真实变化时，撤下上一查询的失败提示。错误使用独立查询代际，等待中的旧失败不会重新覆盖新查询；仍保留正常运行、取消、子页面草稿及插件生命周期检查。已发出的外部操作不被撤销。
- 快捷编辑器的「运行」改为「选择操作…」。操作选择头持续显示当前面板及「全文」，搜索时也保留；当前接口不提供选区文本，不承诺只处理选区。
- 正则提取明确为全部 N 个匹配，选中结果只定位原文，不限制提取范围。原有数量上限及错误禁用保持。
- 文本对比的编辑器来源候选显示语言、行数、字符数，仍载入文本副本，不展示正文片段或承诺实时绑定。
- URL 组件编码说明空格变为 %20、加号变为 %2B；解码不会把加号当空格。不改变 encodeURIComponent/decodeURIComponent 算法。

## 验证

根查询实际 controller/session 行为回归覆盖当前失败、同值输入、查询切换与清空、prepare、迟到异常及非抛出失败、旧运行与新 busy 归属、子页面错误和成功交付。独立审查补验返回/重置及失效插件保护。最终 npm 测试入口通过；插件源码释放、架构及已有正则提取/编解码核心检查通过。

末版 `8f94a16` 类型检查、Vite 构建与官方原生 AppImage 打包均 exit 0。新 Linux X11 QA 实例实际确认：Mousepad 启动失败仍准确显示，改查询与清空后旧错误撤下；QuickEditor 输入筛选词后「面板 2 · 全文」持续可见，Esc 回原面板；Diff 来源菜单显示语言/行数/字符且保留副本说明；Regex 定位第二条仍明确提取全部三个匹配；URL 组件与空格/加号短规则完整可见。未为文案变化重复执行已通过的转换与输出全流程。

首次 History 快捷键失效、Linux 缺 gtk-launch 等既有环境或未定位问题不在本批修复范围。QuickEditor 当前仍按全文处理，未新增选区语义；Diff 来源是载入时副本，统计不能保证区分所有等长内容。
