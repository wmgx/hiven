# 历史多条目打包复制

复用 History 的「选择文本」会话，不新增选择器或页面。可跨搜索选 2–20 条文本，右侧明确显示选择顺序，可上下调整。原「继续处理」、两条对比、顺序粘贴队列继续独立；「打包复制」只把一个完整文本块写入系统剪贴板，不启动队列或外部粘贴。

分隔符支持换行、空行、自定义。自定义按输入原样使用，空字符串直接连接，不解释 `\\n` 等转义。预览展示完整结果；合并结果上限为 1 MiB UTF-8（包括分隔符），超限明确拒绝，不截断。

复制时重新读取所有完整条目（不使用列表 preview），验证选择时 hash，并在完整读取后检查最新索引，拒绝已删除或变化的条目。复制前检查会话仍有效、没有取消或离开焦点。读取、写入失败均保留选择和分隔符，可直接重试。成功也保留当前会话，并在原状态区确认。

调用受限 `clipboard.writeText(text, { recordInHistory: false })`，原生宿主负责本次输出不被 History 再录入。插件本身不改写、删除或新增历史，不接触其它插件数据。

逻辑验证执行 `node scripts/test-clipboard-text-merge.mjs`：全文/顺序/自定义分隔符、UTF-8 边界、非文本和缺失条目、hash 变化、读取后删除/取消、写入失败再试。原生 UI 和系统剪贴板／历史不变验证由集成验收执行；逻辑测试不替代真实 UI。

Linux 原生验收：跨两次搜索选择完整合成文本，换行、空行和自定义分隔符复制均与全文预期一致，后台运行后原生历史索引不变、选择保留；未启动队列。测试结束恢复隔离 profile 原历史开关。
