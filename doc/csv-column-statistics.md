# CSV 工作台列统计

沿用表格标题上的现有列选择，不增选择器。选择一列或多列后，在筛选控件与表格之间紧凑显示每列求和、平均和去重计数，以及有效数字／空值／无效／超范围数量。多列结果可在摘要区域滚动查看，规则可展开。源数据不修改。

## 数据范围与更新

统计输入是 `finalTable`：完成解析、转换、当前筛选／SQL 和投影后的全部结果，**不是** 1500 行输出预览或 5000 行表格预览。范围标注全部结果或当前筛选结果和行数。未完成全量处理时不发布预览统计。列选择、单元格定位、范围和排序以结果中的稳定位置标识，而不是标题文字绑定；重复标题不会互相覆盖或串列。重复的交互标签追加从 1 开始的序号，复制列标题与完整导出仍使用原始标题。筛选、排序及输出格式切换保留列选择；投影重排、增删列或源标题结构变化会清除旧的列／单元格／范围选择及位置排序，防止旧状态绑定到另一列。零行结果仍保留结构未变的选择。编辑源、分隔符、标题模式或转置时清除列选择。行／单元格范围在结果变化时清除。换列、筛选、源及参数变化均取消旧计算，旧回执不得更新新结果；按2000单元格让出执行权，保持取消能力。

## 数值与去重规则

- 仅十进制及科学计数法；解析数值时忽略两端空白。空字符串、纯空白和 JSON 缺失/null 不当作0。
- 不接受千位分隔符、十六进制、百分号、NaN、Infinity。输入最多512字符、100位有效数字，显式及规格化十进制指数绝对值最多1000；超范围单列计数，不悄悄溢出或当0。
- 使用插件私有 BigNumber 配置。有效数求和精确；平均最多20位有效数字，四舍五入，需要舍入时显示≈。无有效数显示“—”，而不是0。
- 去重计数覆盖所有非空原始字符串（包括非数字／超范围），区分大小写及首尾空格，与现有行去重保持逐字符相等规则；`1`、`1.0`、` 1` 是三个不同值，纯空白均不计入。
