# 撤除后台 Observation 采集实验

用户要求删除自学习能力后，继续撤除以发现重复工作流为目的的 Observation 原始采集实验。此文取代此前交付中“Observation 仍保留”的范围说明。

删除 App 启动注册、截图/OCR 和按键轮询、原型配置迁移、旧 enabled 恢复、权限授予后自动恢复、重试、设置 tab 与对应 locale。删除无人共享的 desktop_capture/keyboard_observation 原生实现与命令注册，不仅隐藏 UI。

旧 `behaviorObservation`、`keyboardObservation` 和旧插件配置可继续作为未知持久化字段存在，但没有读取执行它们的观察器。未增加清理、迁移或数据库删除；旧记录与 blob 保留。新“猜你想干”继续默认关闭，只存最小动作元数据；手动 SavedAction、别名与显式更新不变。

显式“保存截图到文件”使用剪贴板 PNG 和通用 blob 原生另存，与观察器完全独立，接口和实现保留。未改系统权限，未运行屏幕或按键采集，未读取真实记录。

验证包括：类型、架构、前端与原生构建；旧 enabled 合成配置水合不写存储；前后端无观察命令或启动引用；手动保存和预测关键逻辑检查；隔离 profile 加载合成旧开启配置后的真实原生设置、搜索、普通工具与预测开关检查。

本次 Linux 原生 AppImage 验收通过。隔离 profile 的 WebView 重载后，两项合成 enabled 标记保持开启，预先写入的两份合成观察记录保持原值；设置无 Observation，搜索无对应动作。普通 JSON 格式化、手动保存别名并重放、显式复制全文均通过；合成保存项已删除，预测建议开关验证后关闭并清空。未调用任何截图/OCR 或按键采集命令。本次结论不包含 Windows/macOS 运行验证。
