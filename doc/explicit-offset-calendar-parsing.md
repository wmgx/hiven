# 显式偏移日期不经过宿主 DST 解析

时间助手 1.10.2 将搜索即时答案、转换命令和日期时间工作台的显式偏移日期统一按日历字段构造 UTC 墙钟，再减去输入偏移。不再先用宿主本地 Date 解析，因此本地夏令时缺口不会悄然改动输入钟点。

支持数字年-月-日、可选空格或 T 分隔的时分、可选秒与 1–3 位小数秒，以及既有数字偏移、UTC/GMT、Z。字段回读检查拒绝日期、小时、分钟和秒溢出；偏移限制为 ±14:00，非法或重复偏移不退回本地时区。显式日期搜索的年份范围检查也不依赖宿主本地年份。

无偏移的搜索与转换命令保留原本地 Date 语义；工作台有明确选中偏移，因此按选中值计算。数字时间戳仍为绝对瞬间，不重复应用偏移。显式偏移日期及工作台不再依赖 Date.parse 偶然接受的自然语言格式；本次没有扩展时间引擎或修改系统时区。

## 验证

仅给隔离原生应用进程设置 `TZ=America/New_York`，WebView 实际报告该时区。旧版真实 UI 重现 `2026-03-08 02:30:00+00:00` 得到 `1772940600000`，晚一小时；新版显示和复制正确值 `1772937000000`。

再次搜索正确时间戳得到 `2026-03-07 21:30:00-05:00`，真实粘贴到外部 Mousepad 后复制回，文本一致；重新解析并复制仍得到原时间戳。非法日期 `2026-02-30 02:30:00+00:00` 没有可复制答案，换回有效输入恢复正常。结束后应用进程恢复默认 UTC 环境。

逻辑检查在 UTC、纽约和上海进程时区覆盖三条入口、春季缺口、秋季重复小时、跨年、闰日、Z、毫秒、非法字段及重复偏移；无偏移输入保留既有语义。类型、架构、前端及原生构建通过，并有独立语义审查。原生 UI 仅验证 Linux 的纽约进程时区及上述搜索复制路径，未声称其他平台或全部工作台交互经过原生验收。未使用真实 API、用户文件或全局时钟修改。
