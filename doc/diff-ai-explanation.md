# Diff 一句话解释

在既有 Text Diff 双栏编辑器中使用「AI 解释」。非空单侧作为粘贴的 diff，双侧均有内容时作为完整修改前/修改后文本。按钮旁展示已配置提供方和模型；只在点击时发送，不读取其他文件、剪贴板或历史。

- 复用 `host.ai` 的 preflight / stream / cancel，插件声明 `ai.use`，不新增通用宿主协议。
- 前置检查只读配置元数据；发送前重新检查选定配置，不自动回退到其他模型。未就绪可以重新检查、进入现有 AI 设置；缺少 ai.use 时提供插件权限入口。
- 两侧总计上限 60,000 JavaScript 字符（UTF-16 单元），超限拒绝，不静默截断。响应超过 2,000 字符或未正常完成不展示部分结果。请求超时 60 秒取消。
- 输入以 JSON 字符串作为不可信引用材料，要求一句话纯文本解释、禁止执行命令/工具/文件/网络访问。调用仅请求 text.generate；继承宿主 Codex 已有 read-only/baseInstructions 边界，插件没有新增执行能力；非文本工具 item 会取消并报失败。此处没有新增提供方级工具禁用协议。
- 编辑文本、配置变化、取消和组件卸载撤销当前请求；晚到的 run.started 也会取消，旧结果不会覆盖当前输入。失败/取消保留编辑器文本，可重试。

独立逻辑验证：`node scripts/test-diff-explanation.mjs`。模拟提供方覆盖完整输入、注入材料引用、大小限制、前置检查/配置变化、无终止响应、超长响应、工具事件、取消后晚回执、超时；不请求真实模型。真实原生 UI 与授权的一条合成 diff 使用由集成验收统一完成。

Linux 原生验收：既有提供方进行了一次显式合成输入调用并返回一句话。桌面键盘输入未完整送达原计划的多行样例，因此本次不宣称完整 diff 语义准确性已验收，也未追加模型调用。随后使用既有剪贴板来源加载完整合成 diff，复制原侧核全文一致、设置往返保留、输入变化清除旧解释。取消、错误、超限和晚回执由模拟提供方测试覆盖。
