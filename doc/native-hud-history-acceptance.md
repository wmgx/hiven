# 原生 HUD 与 History 集成验收

本批在隔离 Linux X11 桌面（Xvfb / xfwm4）运行内嵌生产前端的 Tauri AppImage，通过 WebKitWebDriver 与真实系统键鼠操作验收。外部目标为隔离 Mousepad；所有输入均为合成文本和图片，没有访问真实用户历史或调用真实 API。没有发布应用或部署。

## HUD

仅在普通 Hiven 窗口都不可见时显示一个不可聚焦、置顶、鼠标穿透的临时窗口。普通窗口可见时沿用现有 toast；带恢复操作的通知仍留在原窗口可供查看。HUD 接收固定等级、语言/主题、截止时间，以及可选的受限数字计数，不接收原始通知文本、路径或剪贴板正文。

已实测 Launcher 当前全文复制成功 HUD；外部编辑器在提示前、中、后输入的合成字符串连贯且完整，焦点不变。截止后检查原生窗口 `is_visible=false`。队列长按交付失败产生错误 HUD，显示 0/3 和剩余数量，不展示正文；随后重试成功。普通可见窗口通知没有额外显示 HUD。截图已查看。

验收发现并修复：Linux 首次创建需避开 UI 线程上的同步 WebView 创建；鼠标穿透必须在首次 show 完成 GTK 窗口创建后设置，否则 Tao 对未创建 GdkWindow 解引用会崩溃。状态锁现不跨窗口 API 调用，晚 ready、取消、过期、owner 变化有身份与顺序检查。保留无正文的固定阶段原生 telemetry 供跨平台排障。

macOS / Windows 的焦点、透明背景和多显示器位置没有本批实机证明；Linux 验收不替代这些平台验证。

## History 与队列

固定/编辑/纯文本验收见 `clipboard-history-quick-actions.md`；三次跨搜索选择、逐条全文交付、失败重试、取消释放的原生验收见 `clipboard-paste-queue.md`。仍使用原选择区、预览区与底部状态区。

隔离 History 原设置在结束时恢复为 enabled=false、recordText=true、recordImages=true、recordFiles=true；临时通知 fixture 已禁用，队列取消，临时快捷键释放。

## 检查范围

应用 TypeScript 检查、架构边界、diff check、生产前端构建、原生构建及新增关键逻辑检查通过。本批未运行整个历史测试集。此前检查发现 `test-current-text-delivery.mjs` 的 VM mock 缺少现有 `pasteRecovery` 依赖，并沿用“原生粘贴失败关闭会话”的旧断言；未为使测试变绿而改回该过时行为。

## 2026-10-13：固定结果与前台路由

沿用原被动 HUD，仅为当前素材复制/粘贴、显式粘贴队列添加宿主固定结果回执：复制成功、原生粘贴发送成功、复制失败、粘贴失败、已复制但自动粘贴失败，以及队列结果。`fallback: copied` 从实际交付结果透传，不解析原始错误；普通失败不声称保留。队列失败保留只用于当前有效的会话快照。原生发送成功不等于目标应用已经接受或保存内容。未给原本静默的其他动作增加提示。

回执只含随机操作身份、版本和固定结果枚举；原生验证身份格式、等级匹配和版本范围。相同操作更新，重复/旧版本拒绝；无关成功不覆盖尚未过期的失败，同操作重试成功可解除。更新卡片不先隐藏再显示。取消、替换以及内部停止/热键重载都会撤下队列回执。保留原有绝对截止时间、owner、晚 ready 和旧计时器保护，无消息积压或常驻任务中心。

路由先看自有窗口键盘焦点，再用受支持平台的只读前台身份确认外部应用；查询失败、未知或自有原生对话框不推断为外部。这保留 macOS 非激活 Launcher 的优先级。Linux 只在明确 X11 会话查询有界的活动窗口/PID，不取标题、正文或持久化身份；局部兼容 xfwm 的活动窗口 `[XID, 0]` 零填充，未放宽其他窗口算法。Wayland 不猜测前台。Windows/macOS 分支有实现但本轮未实机验证。

最终内嵌生产前端的 Linux X11 Tauri 构建，在原隔离 profile、合成 GTK 外部编辑器验收：

- **真实操作**：当前素材完整复制，HUD 显示具体复制结果；外部编辑器在提示前、中、后连续输入完整，显式手动粘贴与原文相同；到期原生窗口隐藏。实际当前素材原生粘贴，外部全文正确且 HUD 显示发送结果。
- **真实失败与重试**：使用隔离 profile 原有单条合成历史建立队列，保持快捷键按下超过交付期限，外部文本未增加，HUD 显示 0/1、当前条目保留；松开重试，全文正确交付，原失败原位更新为 1/1。没有启用历史记录或新增历史样本。
- **真实 fallback**：捕获隔离目标后关闭该目标，再执行当前素材粘贴；完整剪贴板写入成功、原生粘贴失败，所属页面显示“已复制，自动粘贴未完成”，原材料编辑视图仍为完整原文。
- **明确为合成回执注入**：通过测试脚本向现有 native `route_toast` 输入固定元数据，验证后台 Hiven 独立窗口仍可见时 HUD 正常路由；无关成功不覆盖失败，同操作重复/旧版本被拒绝，重试成功更新，旧 ID 撤销不影响新回执，取消后晚回执不复活，期限后隐藏。这些注入不代表真实业务交付。
- **真实输入与画面检查**：上述注入期间，在 HUD 覆盖区域实际点击，事件到达外部 GTK 文本编辑器；前台窗口不变，连续输入 `start|through|end|` 完整。查看复制及最长英文 fallback 截图，文字完整。直接窗口 hide 因原有权限被拒绝，清理改用已有 `hide_plugin_surface_window`，未新增权限。

初次检查发现隔离启动器缺少会话类型标记，新路由按未知状态不显示 HUD；在已实际运行 Xvfb/xfwm 的隔离启动器补上 `XDG_SESSION_TYPE=x11`，产品平台检查保持不变。首次 xfwm 零填充查询未通过，修正上述局部读取并重新构建后完成验收。一次尝试替换只读 Tauri invoke 的测试注入未生效，未计作模拟失败验收；fallback 最终由真实隔离目标关闭验证。

独立审查指出内部 stop 清空队列后遗漏撤销回执，已修正并补逻辑检查，复核无阻断项。TypeScript、架构边界、toast/队列交接逻辑、原生回执与零填充检查、生产前端及原生构建通过。没有真实 API、用户历史、用户 Mac 操作、发布或部署。macOS/Windows、Wayland 展示、多显示器混合 DPI、全屏 Spaces 和读屏器仍无本轮实机证明；不以 Linux 单屏结果外推。
