## 1. 目标与成功标准

把散落的正确直觉收敛成**一套输入行协议**：

| 成功标准 | 说明 |
|----------|------|
| S1 同构 | 搜索 / 参数 / 执行三阶段共用同一输入行骨架，不出现「翻页式」第二页表单 |
| S2 可撤销 | ⌫ 在空输入时删除命令标签 = 返回上一步；不设返回按钮 |
| S3 纯函数即时 | 纯函数类工具输入即预览；回车只决定输出去向 |
| S4 去向显式 | 去向徽章常驻：`↵ 复制` / `⌘↵ 粘贴到前台` / `⇥ 切换` |
| S5 无帧动画 | 键盘导航不叠加帧过渡动画；Launcher 本体保持瞬开瞬关 |

## 2. 三阶段协议

### 2.1 01 搜索（维持）

- 信息架构不变：query + 混合列表 + Object Block / Recent Hint。
- 可享用包三键帽 / 列表行质感；**禁止**改搜索 IA。

### 2.2 02 参数（命令标签 + 下拉）

```
┌─────────────────────────────────────────────────────┐
│ 🔍 [ Base64 编码 ]  输入要编码的文本…                 │
└─────────────────────────────────────────────────────┘
│  ▸ option A                                         │
│  ▸ option B   ← 与搜索列表同构的下拉列表               │
└─────────────────────────────────────────────────────┘
```

| 必须 | 禁止 |
|------|------|
| 命令塌缩为行首**蓝色标签**（ObjectBlockToken 同族视觉） | 行内 chips 多参数堆叠 |
| 参数选择保持**下拉列表**（与搜索列表同构） | 参数做成键帽 token |
| 空输入 ⌫：删除标签 → 回到搜索 | 单独「返回」按钮 |
| 已选参数以轻量灰值块显示（沿用 collect-input 格式） | 为切参数加页面级转场 |

**⌫ 语义（包四参数标签）:**

- 输入非空：⌫ 只删字符。
- 输入为空：**一次** ⌫ 删除命令标签并返回搜索（与 2026-07-26 Object Block 一次删除对齐；审查原文两段式作废）。

### 2.3 03 执行（Live Preview + 去向）

```
┌─────────────────────────────────────────────────────┐
│ 🔍 [ 格式化 JSON ]  · pretty · 2-space               │
└─────────────────────────────────────────────────────┘
│  ╭─ preview well ──────────────────────────────╮    │
│  │  { "a": 1 }                                 │    │
│  ╰─────────────────────────────────────────────╯    │
│  [↵ 复制]  [⌘↵ 粘贴到前台]  [⇥ 切换去向]              │
└─────────────────────────────────────────────────────┘
```

| 必须 | 禁止 |
|------|------|
| 纯函数工具：输入/参数变更即更新 preview | 把网络工具伪装成「无等待」 |
| 回车 = 执行当前去向；不另开确认页 | 用 busy 转圈掩盖本可预览的纯函数 |
| 去向徽章常驻，`⇥` 专切去向 | `↑↓` 兼做去向切换 |
| preview well 与 V5 空井同材质语言 | 引入 Monaco 为默认预览器 |

**非纯函数（翻译等）:** 保留 busy（包一 running-pulse）；preview 可显示上次结果 + stale 标记。

## 3. 数据与帧模型（实现边界）

```
SearchFrame
  └─ select command
       └─ ParamInputFrame? (0..n params, list UI)
            └─ CollectInputFrame / ResultPreviewFrame
                 ├─ livePreview: string | null
                 ├─ outputTarget: copy | paste-foreground | …
                 └─ secondaryTargets[]
```

- Framework **不**引入 `DiffSurface` / 语义 diff；preview 是 launcher 帧协议内的文本井。
- 插件通过既有 `execute` / collect-input 返回预览文本；新 API 若需要，扩 host SDK，插件不 import 私有路径。
- Object Block 推荐（ranking + textMatch）与 live preview **不同层**：前者在搜索列表，后者在命令已选定后的执行帧。

## 4. 键位分工（跨阶段不冲突）

| 键 | 搜索 | 参数 | 执行 |
|----|------|------|------|
| `↑↓` | 列表 | 参数列表 | 不用于去向 |
| `↵` | 运行/进入 | 确认参数项 | 执行当前去向（默认复制） |
| `⇧↵` | — | — | **粘贴到前台** |
| `⌘↵` | 自定义参数（既有，仅搜索） | — | **带回 Launcher**（Object Block） |
| `⇥` | workflow object（既有） | — | **切换去向** |
| `⌫` | 删字；空则删 Object Block（一次） | 删字；空则删命令标签 | 删字；空则退回参数/搜索 |
| `Esc` | 关闭 | 退回 | 退回 |

IME：composition 中的 Enter 永不确认（既有全局规则）。

## 5. i18n

所有徽章、空预览、stale、错误文案走 `palette.*` / 插件 locale，禁止硬编码中英。

建议 key（实现时补齐）：

- `palette.outputCopy` / `outputPasteForeground` / `outputSwitchTarget`
- `palette.livePreviewEmpty` / `livePreviewStale`
- `palette.commandTagRemove`（无障碍）

## 7. 实施顺序建议

1. 输入行命令标签组件（复用 ObjectBlockToken 视觉 token，不复用 clipboard 语义）
2. Param 帧改为「标签 + 同构列表」（行为先对齐，再精修样式）
3. Live preview 井 + 纯函数接线
4. 去向徽章 + ⇥ 切换
5. ⌫ 返回链与 Object Block 一次删除语义统一
6. i18n + 真机 DOM 验收

**非目标:** V4 立体黑 / V5 空井视觉（并行文档）；包四不阻塞它们出稿，但 preview well 材质应与 V5 同族。
