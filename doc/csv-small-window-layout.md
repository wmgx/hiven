# CSV 小高度布局

在支持的最小窗口（Linux 实测内容区 704×480）中，全量结果提示、列统计与规则说明同时出现时，统计区此前不参与收缩，表格被压到约 9px，无法换列核对。

本次仅调整 CSV 插件布局：统计允许收缩并内部滚动；表格按现有 36px 表头、32px 行高及滚动条保留至少两行空间；表格容器在内容超出时允许滚动。窄且矮窗口的读取/转换控件并排，减少工具栏占高。未改变窗口最小尺寸或统计算法，未新增面板。CSV 版本更新至 1.11.1。

## 验收

在隔离 profile 的真实 Linux AppImage 中使用 10,000 行合成文本：最小窗口选列、展开规则后表格高度为 118px；滚轮可读到说明结尾；换列后统计更新；复制全文解析得到 10,000 项，末行完整。Shift+Tab 可从表格回到输出、复制和另存控件；键盘打开原生另存对话框并取消。8 列合成表格的水平滚轮可从左端滚到右端，宽度 864px 的内容在 678px 视口中可达。恢复默认尺寸后表格随空间扩展，外层无多余滚动。

独立审查者检查了最小尺寸、规则滚动、复制/另存焦点和正常尺寸截图，未发现新阻断。类型检查、架构检查、前端构建和原生构建通过；未新增样式单测或重跑统计算法测试。未使用真实用户数据、账户或 API。
