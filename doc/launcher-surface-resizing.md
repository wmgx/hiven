# Launcher 工具窗口尺寸

## 范围

共享 Launcher 仅对当前工具明确声明 `shell.resizable: true` 的页面开放原生边缘拖动。搜索、参数和普通结果页沿用紧凑自动尺寸；独立插件窗口不在本次范围。

当前会受此合同影响的产品包括：日期时间、AI 写作、二维码、随机数、计算器、正则、文本整理、格式化、编解码、JSON、文本对比、翻译和 CSV。它们已有声明，本次不改变插件动作、算法、权限或保存格式。

## 交互合同

- 工具首次进入使用声明的默认尺寸与最小尺寸。宿主外边距另计 24px；原生按当前屏幕工作区限制初始大小及位置。GTK 暂无显示器信息时保留已有有效窗口大小，否则回退既有紧凑尺寸，不能放行无限大的声明。
- 用户拖动后，当前工具输入和结果刷新不重新套用默认尺寸。工具内容随实际窗口伸展，不保留旧默认宽高的 CSS 上限。
- 返回搜索、关闭或普通重新唤起恢复紧凑约束。不持久保存用户尺寸。
- 粘贴时的预期临时隐藏不退出工具；未插入而恢复原窗口时保留本次尺寸、正文及已有失败提示。
- 只给 Launcher 自身调整约束。旧工具或旧窗口会话的异步请求不能覆盖新会话。
- 关闭背景必须是左键从背景开始并在背景结束的点击。原生边缘拖动或正文选择即使结束在透明边缘，也不解释为关闭；取消的指针序列不沿用到下一次点击。

## 验收边界

- 真实桌面为 Linux X11，使用隔离 QA profile 和合成文本。没有测试 Windows/macOS 的真实拖动、焦点或输入法，也没有测试 Wayland。
- 13 个声明工具通过同一宿主合同生效，本次真实代表覆盖 CSV、JSON、URL；不把它们等同于其余每个插件的布局都已逐项验收。
- 英文 JSON 实测最小宽度，中文 JSON 实测最小宽高；没有改字体大小或通过强设窗口几何替代实际拖动。
- 图像、Quick Editor 已有环境问题、独立 History 窗口及各工具的短暂通知不在本批范围。没有修改账号、网络、安全配置或执行真实 AI。
- 截图和窗口读数留在内部 QA 记录；发布内容仅代码、合成逻辑测试与本文，不包含截图、运行日志或用户资料。
