# JSON 光标字段路径复制

JSON 工作台输入栏增加「复制 JSONPath」「复制 JSON Pointer」，输入与输出编辑器同时通过既有 `onReady` / Monaco action 注册同名上下文菜单操作。输出栏不再增加按钮，以免挤占已有输出动作。按键调用可通过编辑器命令面板选择动作；按钮本身可 Tab/Enter 操作。

定位读取当前编辑器模型及 caret offset，不读取框架内部状态，不改用户手写表达式或输入。JSON 语义全部保留在 `json-tools` 插件。JSONPath 一律使用带 JSON 字符串转义的方括号形式（数组为数字下标），例如 `$["users"][0]["display.name"]`；JSON Pointer 按 `~→~0`、`/→~1` 转义，例如 `/users/0/display.name`。

光标须落在键或值的 token 内；空白、逗号、冒号不猜附近字段。对象/数组括号定位该容器本身；根 JSONPath 是 `$`，根 Pointer 是空字符串，并有专门复制成功文案。token 采用左闭右开范围，紧靠 token 后的分隔位置不算 token 内。

完整 JSON 必须有效；任何对象有重复的解码后键名都拒绝（包括 `a` 与 `\u0061`），避免同一路径歧义。不同对象的同名键不冲突。上限为 1,000,000 UTF-16 单元与 128 层嵌套，超限拒绝不截断。

复制使用当前文本和 caret 快照。内容/光标变化、编辑器重新绑定、退出或新一次复制均撤销旧回执展示资格；复制失败保留原文/表达式。编辑器 action 在卸载和语言变更时清理/重绑，不改 framework。

逻辑测试：`node scripts/test-json-cursor-path.mjs`，覆盖键/标量/容器、数组、空键、点号/斜杠/波浪号/引号/反斜杠/Unicode、根路径、非法 JSON、重复键、光标空白及范围限制。真实 Monaco 光标、系统剪贴板和按钮布局由集成者统一原生验收。

2026-10-11 Linux原生验收：使用真实Monaco键盘输入与光标移动，users数组内display.name值复制JSONPath与Pointer准确；a/b~c键得到 `/a~1b~0c`。非法JSON、重复键和空白位置均提示拒绝，剪贴板不变。原生验证使用合成文本；输入自动化改为清空后键入并用系统复制核对原文，未把失败的粘贴尝试算作通过。
