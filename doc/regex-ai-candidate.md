# 正则 AI 候选

正则测试器主页面增加可折叠的候选入口，复用 `PluginAiApi` 与设置中的服务、模型和推理强度。插件新增 `ai.use` 权限，版本更新为 1.3.0；未引入聊天页面或新的 AI 框架。

点击「生成候选」才发送描述及可选正反例，不发送测试原文、手工正则、剪贴板或历史。每行一个原样例子：正例至少匹配一次，反例不能匹配。描述最多 4,000 字符，正反例合计最多 12 条，每条最多 4,000 字符，超限拒绝且不截断。

仅接收绑定服务/模型的完整 completed 响应，严格解析仅含字符串 pattern/flags 的 JSON。流中间状态不编译、不运行、不采用。响应最多 16,000 字符，表达式最多 4,000 字符，生成含前置检查最多 60 秒；完整候选在已有隔离 worker 中编译，并逐例执行，每次最多 1 秒。失败提示例子序号，禁止采用；无例子时仅确认可编译，不宣称正确性。通过后仍需显式「采用候选」，才更新表达式和 flags。

修改描述、例子、手工表达式、flags 或原文，以及离开、owner 失效、配置变化或取消，均撤销候选和旧请求。即使 provider 忽略 abort，旧响应也不能恢复候选。输入保留，重试必须再次点击。设置沿用现有设置入口，失败不切换服务。

定向验证使用模拟 provider，覆盖完整流门槛、取消与晚回、配置变化、失败反例、格式及大小限制、超时后重试；worker 另有真实线程超时和恢复测试。没有真实 API 自动测试。

## 原生交互验收

2026-10-11，在隔离 profile、Xvfb + 原生 WebKit WebDriver 中，使用官方 debug AppImage 包含的生产前端（`tauri://localhost`，无开发服务器或 web bridge）。沿现有 Launcher → Regex Tester → AI 设置确认原有 OpenAI ChatGPT / GPT-6.1-Sol 配置后返回，仅点击一次「生成候选」。未用 CLI 提问，也未运行真实 API 自动测试。

合成需求为提取全局、大小写敏感、带词边界的 `ORD-` 加三位 ASCII 数字；提供 2 条正例与 3 条反例。实际候选为 `\bORD-[0-9]{3}\b`、flags `g`，全部例子通过。采用前手工 `[a-z]+` 与 150 行、4,499 字符的测试原文保持不变；点击采用后得到 150 个匹配，描述保持不变。

通过原有「提取全部并继续」返回文本工作台，再显式点击「复制当前文本」。外部 X11 剪贴板读回与完整 150 条订单号逐字符一致，共 1,199 字符，包含界面 100 条预览之外的结果。未启用真实历史记录、未修改 AI 配置；登录 profile 保存在打包目录之外，凭证及原始 provider 日志未进入仓库。

截图和机器验收记录仅留在本环境 `/workspace/hiven-native/regex-ai-{before,candidate,adopted}.png` 与 `regex-ai-acceptance.json`。取消、失败、配置变化等异常使用模拟 provider 验证，未为这些场景重复真实请求。
