# Clean Agent Text：保守拆除终端盒框

入口：搜索 `clean agent text`、`claude code`、`清理 AI 文本` 或 `去除边框`，进入现有文本工作台。此操作也在工作台「文本」分类中。原文与结果并列预览，复制沿用完整结果交付；不读取终端、不调用模型、不自动覆盖原文。

默认仅拆除完整的 `╭─╮ / │ │ / ╰─╯` 或 `┌─┐ / │ │ / └─┘` 纯线条盒框。每行必须拥有同一外侧缩进、正确边框、两侧至少一个空格且列宽与上下框一致。ASCII `+---+ / | |` 需要显式勾选。只移除边框与两侧各一个填充空格，额外空格属于原文并保留，不猜测右侧空格是否终端补齐。

常见中日韩全角字采用两列，ASCII 采用一列；emoji、组合字符、终端转义、制表符和其他宽度不确定字符不尝试清理。残缺、带标题、嵌套、Markdown 表格、代码围栏内的盒框保持原样。遇到已识别但不合法的外框开头，保留至对应闭框或文件末尾，避免继续误清理内部独立形状。不处理单独的竖线、横线、项目符号或提示符；不能根据外观推断任意文本是装饰。

## 合成验收材料

下例第一框第二行有三个尾随空格，必须完整保留；框外 Markdown 表格不变。

```text
## Notes
| a | b |
|---|---|
╭──────────────────╮
│ cat input | sort │
│   call(a | b)    │
╰──────────────────╯
╭──────╮
│ 中文 │
╰──────╯
```

等价无歧义 JS 输入与期望结果（便于验收全文）：

```js
const source = '## Notes\n| a | b |\n|---|---|\n╭──────────────────╮\n│ cat input | sort │\n│   call(a | b)    │\n╰──────────────────╯\n╭──────╮\n│ 中文 │\n╰──────╯';
const expected = '## Notes\n| a | b |\n|---|---|\ncat input | sort\n  call(a | b)   \n中文';
```

## 验证

纯逻辑检查：`node --experimental-strip-types scripts/test-clean-agent-text.mts`。覆盖完整框、显式 ASCII、CJK 双列宽、emoji 等不确定宽度、Markdown 与数学/管道符保护、围栏、残缺/嵌套/带标题框、CRLF/末尾换行，以及 13 万行完整输出不截断。

实际工作台、键盘、外部编辑器完整复制验收由主集成流程记录。

## 原生交互验收

隔离 Linux X11、合成材料验证通过：中英文搜索进入既有工作台，137 字符原文得到 65 字符结果；完整复制到外部 Mousepad，再全选复制读回，与期望全文逐字一致（包括代码缩进和尾随空格）。切回工作台后原文逐字不变。ASCII 示例默认保持原框，勾选后得到正文。

此操作的复制成功会保留当前工作台，便于返回原文；其他工作台操作仍沿用原完成行为。原文只有用户明确选择接续结果或编辑才改变。退出沿用既有弃稿确认。

纯逻辑、工作台路由／转换集成、类型、架构、差异检查及前端／原生构建通过。截图与全文核对结果位于隔离目录 `clean-agent-{search-zh,preview,external,original,ascii}.png` 和 `clean-agent-ui-result.json`。其他平台未实测。没有读取真实历史、调用模型、增加权限或读取终端；键盘布局需求已取消，未实施。
