# 当前文本另存为文件

## 产品范围

原生 Launcher 根列表中，当前可编辑文本材料提供一个“当前文本另存为…”推荐动作。它保存完整正文，不读取预览、剪贴板、历史记录或来源文件。没有材料时不出现；显式空文本可保存零字节，纯空白以及 0、false 字符串原样保存。图片、文件对象、掩码秘密及 NUL 文本沿现材料资格排除。

用户通过原生保存对话框选择路径，建议名固定为 result.txt，默认从正常 Documents、Downloads、Home 可用目录选取。路径和文件名不继承来源；不根据启发式类型猜格式，不自动补扩展名，也不限制用户正常指定的后缀。保存的是 UTF-8 文本，不执行文件。没有配置文件系统通用插件权限或自动回写来源。

内容在点击时冻结，前后端按 UTF-8 字节限制为 1 MiB，超限明确失败，不截断或 trim。普通同名覆盖确认由原生对话框负责；选择取消不写文件，成功落盘才提示。保存和取消均不清除当前材料或搜索。

## 归属与并发

专用 host 文本票据保存在当前 native webview resource table。三个命令限制 launcher，并在浏览器 relay 中明确拒绝；不是插件 blob 或 source/pluginId 授权。窗口 label 不构成对同一 JavaScript realm 内受信插件的新沙箱。

前端绑定当前材料、query 代际、root controller 与窗口会话；先读取现有 native open session，再复核当前作用域。native 会话检查和资源预留在主线程串行，关闭、隐藏、重开或销毁会令未提交票据失效。旧结果只丢弃自己的票据，不能撤销新操作。

host 单次只允许一个导出；native 最多保留 4 个有界资源槽，已准备票据有效期五分钟。对话框中的已失效资源在实际结束前仍占槽，避免无限创建。一次性 commit/discard 竞争消费票据。

同一会话的原生选框保有焦点租约直到选框结束；旧会话租约不抑制新会话的 blur，迟到释放不触发新会话焦点处理。选择结束后再次复核作用域，才提交已冻结内容与 native 路径。

写入使用同目录临时文件并原子替换。commit 接受后已跨过不可撤销边界，迟到关闭只能抑制旧 UI 提示，不能撤销已经写入的文件。对话框确认至提交之间没有额外的并发文件编辑冲突检测，不声称解决外部程序同时修改。

## 真实桌面进展

- Linux X11 隔离 QA 中，97 字符中文 JSON 当前材料显示单个另存推荐行，键盘选中并 Enter 能打开原生保存框；默认 result.txt，目录回退到隔离 profile Home。
- 使用原生 Name 字段正常坐标操作，明确选择全新 QA 路径 export-current.md。实际写入 109 个 UTF-8 字节，与输入材料 fixture 逐字节一致，没有另加 .txt。
- 保存后 1.18 秒截图可见“当前文本已保存”；Launcher 和原材料保留。第一次通过 Entry 的 AX activate 触发了默认 result.txt 提交，该文件同样比对一致；没有把这次工具激活错误当作产品自动关闭。

- 使用现有文件读取入口重新导回 export-current.md，编辑材料页完整显示原中文 JSON、特殊字符及 version=new；未提交编辑。
- 再次打开另存框并填写全新 cancelled-current.md 后点击 Cancel，该文件不存在，原查询 save 与当前材料保留，没有保存成功提示。

本批真实验收限 Linux X11 同一隔离 QA；未实测 Windows/macOS、系统同名覆盖或所有默认目录分支。空串、过限、写失败及异步竞争由受控模块验证，不冒充 GUI 全矩阵。
