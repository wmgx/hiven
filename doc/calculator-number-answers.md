# 中文数字大写与进制即时答案

复用 calculator 搜索即时答案，每条明确请求最多一个紧凑结果，不新增页面或按钮组。仅按 Enter 时写剪贴板，不联网、无历史写入。

## 中文大写

- `大写 12345` / `12345 大写` / `中文大写 12345` → `壹万贰仟叁佰肆拾伍`，纯整数无货币单位。
- `金额大写 12345.67` / `RMB 12345.67` / `12345.67 元大写` → `壹万贰仟叁佰肆拾伍元陆角柒分`。也支持 CNY、人民币、¥、￥明确金额前缀。
- 裸数字不生成新增答案，不抢占普通计算或时间戳结果。
- 精确十进制字符串处理，接受正负号和前导零，负零归零；以万、亿、兆四位分组补零，整数部分最多 16 位。金额最多两位小数，三位即使全零也明确拒绝，不舍入。整数模式不接受小数。科学记数、千位逗号、混合表达式不猜测。
- 本功能是数字转换，不代替票据格式规范审查；“兆”明确表示 10¹²。

## 进制

- `0xFF` 一行显示十进制 `255` 和二进制 `0b11111111`，Enter 完整复制两行带本地化基数标签的文本。
- `0b1010`、`0o377` 显示十进制与十六进制；`dec 255` 显示十六进制与二进制。
- `255 to hex` / `hex FF to dec` / `bin 1010 to dec` / `二进制 1010 转 十进制` 指定单一目标时只复制一个带必要前缀的数值。
- 输入以 BigInt 精确处理，最多 256 位数字，不丢失超出 Number 安全整数范围的位数。负数采用 `-255` / `-0xFF` / `-0b11111111`，不猜测补码宽度。无小数或隐式八进制；不修改现有普通算式计算。
- 无效输入、超限输入显示错误，不覆盖剪贴板；长结果视觉上沿用已有行布局，但复制内容完整，无截断。

逻辑验证：`node scripts/test-calculator-number-answers.mts` 和 `node scripts/test-calculator-command-mode.mjs`。原生 UI、系统剪贴板、键盘主链由集成者统一验证。

Linux 原生验收：大写 12345、RMB 12345.67、0xFF、-255 to hex 的 Enter 复制结果准确；金额多余小数和非法二进制拒绝且剪贴板不变。中文查询使用系统剪贴板输入，未验证中文 IME 上屏。
