# History 快捷操作

此批复用 History 已有收藏数据与收藏筛选，不引入第二套 Pin。`Alt+P`（macOS `⌥P`）在搜索/列表焦点内立即切换收藏，已有星标按钮、收藏标题编辑、免清理策略照常使用。macOS 使用物理 `KeyP`，兼容 Option 产生的字符；不注册全局快捷键。

文本 History 原本只保存纯文本，不保留 HTML/RTF。普通 Enter 仍沿原 `host.paste.pasteText`；新增 `Alt+Enter`（macOS `⌥Enter`）及「粘贴为纯文本」按钮明确调用同一路径。图像、文件不能误入纯文本快捷操作。粘贴前重新读取完整条目，已删除不粘贴；宿主继续负责目标捕获与交付失败反馈。

「编辑正文」在原预览区编辑完整文本，不新开 surface。界面明确「保存会修改这条历史记录，不改动剪贴板」。保存/取消为显式操作，编辑期间原列表与查询暂时禁用、未保存状态交由现有宿主离开确认保护。取消不写存储；保存保持 ID、收藏、来源与使用元数据，仅更新正文、摘要、字节数和内容 hash。正文超过当前文本大小限制不会截断；已删除、原文被改或与另一条重复时不覆盖，保留草稿。索引写失败尝试回滚条目，允许重试。同 renderer 多个仓库实例的写入共用顺序锁。

验证：`node scripts/test-clipboard-history-edit.mjs` 用内存存储运行生产 repository；`node scripts/test-clipboard-history-shortcuts.mjs` 检查实际快捷处理函数。Linux X11 原生 UI 已验证 Alt+P 切换原收藏、编辑取消保留原文、明确保存含中文换行的全文、查询保留，以及 Alt+Enter 向 Mousepad 粘贴并逐字核对完整纯文本。macOS 未做实机验证。

## 顺序粘贴队列（1.6.0）

复用「选择文本」中的跨搜索有序选择与上下移动，不新增选择器。加入前读取选中时对应 hash 的完整正文，再确认条目仍存在；最多 20 条、合计 1 MiB，不截断。不改 History 正文。队列保存加入时的独立快照，此后编辑原条目不改变已加入队列。

「加入顺序粘贴队列」成功后，原状态区显示说明、剩余进度、取消与「返回目标应用」。原选择保留，已有活动队列时按钮明确改为「替换顺序粘贴队列」。在目标应用使用 Control+Shift+V（macOS 显示 `⌃⇧V`，不是 Command），每次仅尝试一项；失败显示当前项保留，用户聚焦正确目标后再按同一快捷键重试。订阅/getStatus 只含状态元数据，不传正文；较早的异步状态查询不会覆盖新到的进度事件。

队列已完成 Linux X11 原生验收，详见 `clipboard-paste-queue.md`。

首版原生队列仅启用于 Linux X11；macOS、Windows、Wayland 会明确提示暂不支持，保留选择且不启动队列。快捷键注册冲突单独提示，不伪装为条目读取失败。macOS 键位标注仅说明 Control 语义，不代表该平台现已可用或通过实机验收。

## 历史图片直接另存为（2.0.8）

有效图片条目的上下文菜单提供「图片另存为…」，也可在搜索或列表焦点内按 `Ctrl+S`（macOS `⌘S`）。操作会重新读取当前仍有效的完整历史条目，并把原图 blob 交给宿主现有的原生 PNG 保存对话框；缩略图 blob 只用于预览，不参与导出。保存不写当前剪贴板、不复制文件路径，也不更新历史排序、复制次数或最近复制时间。

同一 surface 同时只允许一个保存事务。读取完整条目时已经删除、过期或界面失效则不开始保存；宿主会在原生对话框打开前冻结原图字节，因此此后的历史删除不改变本次已选定的导出快照。取消或失败保留查询、选择和滚动状态。原生提交一旦发出，文件写入由宿主持有的一次性 ticket 完成，界面关闭只能停止后续 UI 反馈，不能撤回已经写入的文件。
