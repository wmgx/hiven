# 已安装应用别名冲突

设置中的应用搜索别名按去首尾空白、不区分大小写的精确值检查其他已安装应用的名称、本地化名称、发现别名和已保存别名。冲突时列出应用名称及可用路径，禁止保存；不做拼音、前缀或模糊冲突判断，也不扩展到插件改名。

读取旧配置不会清理冲突别名。用户可以修改或清空后保存，取消编辑仍保留原值。保存前再次读取最新持久化别名，防止其他窗口的更新尚未同步时写入冲突；失败不修改内存或持久化配置。未安装应用的残留元数据不阻止保存。

旧配置可能仍有名称冲突：搜索完整应用名时，真实名称（包括本地化名称）比其他应用的同值别名高一个匹配层级，优先于既有收藏、使用频率加分。空查询收藏、无冲突别名和同分稳定顺序保持原规则；正常排序和大结果集的截取使用同一规则。

## 验收

在隔离 Linux 原生桌面 profile 中，先用旧版设置保存 `Mousepad → Vim` 和一个合成中文别名，再启动新版：旧值完整保留，设置明确指出 Vim 冲突；搜索 `Vim` 时真实 Vim 位于首位且默认选中，Mousepad 仍可发现。

通过真实鼠标、键盘完成旧冲突修正、中文别名保存、改名、取消编辑、清空取消与清空保存。再次尝试给 Mousepad 设置 `Vim` 时提示冲突应用和路径，保存禁用，取消后原别名仍在。结束恢复最初的空别名配置，确认正常应用名搜索可用。未使用真实用户配置、历史或 API。

纯逻辑检查覆盖名称来源、自身和未安装应用排除、跨窗口最新存储冲突拒绝及重试、旧配置保护、收藏与使用记录加分、同分顺序和大结果集截取。类型检查、架构检查、前端与原生构建通过。跨窗口竞争由独立存储实例测试覆盖，未将其声称为多窗口原生交互验收；macOS、Windows 未进行原生验收。
