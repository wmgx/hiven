# 千分位格式化

Calculator 1.9.0 复用搜索即时答案与既有 Enter 复制，不新增页面。

输入 `千分位 12345.6700` / `千分位格式化 12345.6700` / `thousands 12345.6700` 得到 `12,345.6700`。也接受 `group number`、`format number` 前缀。裸数字不产生新增答案，原计算、单位、进制和中文大写不受影响。

默认明确采用英文规则：整数每三位一个逗号，小数点为点号。处理全程是字符串切片与拼接，不经过 Number，不舍入、不丢尾零，正负号、负零与前导零都保留（`0001234.0500` → `0,001,234.0500`）。

只接受带可选正负号的十进制整数或完整小数。含逗号输入一律提示歧义，不猜其为千分位还是小数点；科学记数、空格分组、表达式、`.5`、`1.` 均拒绝。数字文本上限 10,000 字符，超限显示错误，不截断。输出始终完整复制，错误不会写剪贴板。

逻辑验证：`node scripts/test-calculator-thousands.mts`、`node scripts/test-calculator-command-mode.mjs`。真实原生搜索、键盘、剪贴板验收由集成者统一进行。

2026-10-11 Linux原生验收：负数与小数尾零、大于安全整数范围的完整数字复制逐字一致；逗号歧义输入显示错误且Enter不改变剪贴板。仅隔离profile合成文本。
