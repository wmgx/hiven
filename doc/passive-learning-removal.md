# 移除被动自学习

被动剪贴板／导航观察、自动归纳、已学规则触发、习惯收藏提示和相应设置已撤除；插件 Host SDK 不再提供学习规则接收器与能力覆盖注册入口。旧的 `automaticLearningEnabled` 配置在读取时忽略，不重写已有存储。

保留用户手动保存的工具、别名、固定项、基本最近使用和浏览器历史搜索排序。`actionPolicy.learnable` 仍是手动保存工具所需的既有配置契约字段，不代表后台学习仍运行。浏览器规则的“导入参数”由用户显式触发，保留此手动功能。

不打开或清理旧 `hiven-learning` 数据库；旧自动浏览器规则仍保存在插件配置内，运行投影继续排除这些规则。此次浏览器迁移不再过滤删除存储中的旧自动规则。诊断行为观察及独立的显式命令建议不是这次撤除的被动学习引擎。

验证包括旧学习开关为 true 的设置水合仍忽略该字段、不写入存储、不破坏手动别名与参数；旧自动浏览器规则迁移保留；手动收藏和别名跨窗口存储、候选稳定性、基础浏览器历史接口。构建与真实 UI 验收由本次集成验证统一完成。
