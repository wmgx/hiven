# 剪贴板历史文本合并

在已启用的剪贴板历史中，用户可以打开「合并文本」，明确选择 2–20 条文本。图片和文件记录不参与合并；此入口不会开启历史采集，也不会自动复制、粘贴或调用 AI。

## 操作

选择顺序就是合并顺序。搜索、筛选和新历史记录不会重排已选项；可以在有序清单中移除条目、向上或向下移动。分隔方式为一个换行或一个空行，保留每条原文的空白和原有换行，不自动去重。

预览读取各条记录的完整正文，不以列表摘要代替。任意一条读取失败时，保留选择并显示错误，不能把缺少部分的结果交给后续工具。修改选择或分隔方式会使旧预览失效。

确认「继续处理」后，完整预览成为 Launcher 的一份文本材料，继续使用现有格式化、清理、提取等工具。结果来源标记为用户处理的文本，不伪装成某条历史记录，也不把内容中的路径重新读作文件。

## 生命周期

合并只保存在当前界面会话中，不新增材料库或持久化格式。取消或关闭组合对话框不删除历史。界面隐藏、退出或新请求使旧读取结果失效；没有确认动作时不会向 Launcher 交付。原有单条历史记录的 Enter 行为保持不变。

跨窗口交付使用定向请求与接收确认。目标按请求身份和材料代际接收，成功后回到列表并显示 Launcher；源界面在确认前保留选择和草稿。超时、取消或显示失败会给出反馈，不把单纯写入临时记录当成交付成功；重复确认不会让已消费的旧材料重新出现。

## 验证范围

纯逻辑回归使用合成记录覆盖数量限制、顺序、混合换行、全文读取、原子失败和取消竞态。共享交付回归覆盖确认丢失、超时、材料代际变化、取消、重复交付及显示失败保稿；设置同步回归覆盖双向启停、删除恢复默认、延迟事件及失败回滚。

2026-10-09 在 Linux X11 隔离配置中，用正式构建的界面和三条中英文合成名单完成以下操作：

- 初始历史关闭，明确启用后才记录。最终同一进程内在独立历史窗口关闭、开启，分别确认新合成文本未入库和正常入库，无需重启。
- 跨搜索保留选择，调整顺序、移除并重新加入；取消组合不删除历史，Tab 可到操作按钮。
- 深色和浅色组合界面可读，完整预览可滚动，继续处理按钮保持可见。
- 三条材料按指定顺序、空行分隔后，继续处理进入 Launcher；编辑器确认完整正文。清理空白、空行、重复项后带回，再编辑并复制，在新文本编辑器中核对完整结果。

存储故障和精确异步竞态通过合成模块验证，未向真实界面注入数据库故障。已有独立窗口不会立即跟随另一窗口的主题变更，本次未扩展全局主题同步。未测试真实中文输入法组合、Wayland 或模型生成。

单条记录自动粘贴另有已观察的旧路径限制：从外部编辑器唤起 Launcher，再由 Launcher 打开历史并按 Enter，历史关闭后焦点回到 Launcher，外部编辑器未收到文本。原生打开窗口、目标捕获及插件粘贴代码与本批基线一致，允许把 Launcher 自身记录为目标；尚未对旧包重演。此路径未算验收通过，需单独修复；合并材料的显式继续处理与复制闭环已通过。

## 独立窗口的设置同步

在历史独立窗口启用或关闭记录后，Launcher 所在窗口需要同步当前插件设置，后台监听才能立即启动或停止。接收端读取当前持久值而非延迟事件携带的旧值；未改变的插件记录保持引用，避免无关设置造成后台重启。删除设置记录或清空设置后也恢复默认关闭。

同步不传递界面弹层状态。写入时合并其他插件、来源及已成功保存的更新；保存失败保留原异常并恢复本次未保存值，不把未保存的启用状态留在内存。此机制使用同源存储事件，不创建新的网络通道。
